# Intuition
The problem asks us to detect a cycle in a grid where we can only move between cells of the same character. A 2D grid is essentially an undirected graph. 

The most elegant and efficient way to detect a cycle in an undirected graph as we build it is by using a **Disjoint Set Union (DSU)** or Union-Find structure. If we iterate through the grid and connect adjacent cells of the same character, a cycle is found the exact moment we try to connect two cells that are *already* in the same connected component. 

Since it's a 2D grid, the smallest possible cycle is a 2x2 square (length 4). We naturally avoid length-2 cycles (going back and forth) because we only process edges once by exclusively looking `Up` and `Left` from our current cell.

# Approach
1.  **Flatten 2D to 1D:** Map each cell `(r, c)` to a 1D index `r * n + c`. This makes it easy to use a standard 1D `parent` array for the DSU.
2.  **Initialize DSU:** Create a `parent` array where each cell is initially its own parent.
3.  **Iterate through the Grid:** Loop through every cell `(r, c)` from top to bottom, left to right.
4.  **Check Up and Left:** For the current cell, check its top neighbor `(r - 1, c)` and left neighbor `(r, c - 1)`. 
5.  **Union:** If a neighbor has the same character, perform a `union` operation. 
    * If the `union` operation returns `False` (meaning both cells share the same root parent), we have found a cycle! Return `True` immediately.
6.  **Complete:** If the loop finishes without detecting any cycles, return `False`.

# Complexity
- Time complexity:
$$O(m \times n)$$
We visit each cell in the $m \times n$ grid exactly once. For each cell, we perform at most two `find` and `union` operations. With path compression, these DSU operations take near-constant time, making the overall time complexity strictly linear with respect to the number of cells.

- Space complexity:
$$O(m \times n)$$
We allocate a `parent` array of size $m \times n$ to keep track of the connected components.

# Code
```python3 []
class Solution:
    def containsCycle(self, grid: List[List[str]]) -> bool:

        m, n = len(grid), len(grid[0])
        
        # DSU parent array
        parent = list(range(m * n))
        
        # DSU Find with path compression
        def find(i):
            if parent[i] != i:
                parent[i] = find(parent[i])
            return parent[i]
            
        # DSU Union
        def union(i, j):
            root_i = find(i)
            root_j = find(j)
            
            if root_i == root_j:
                return False
                
            parent[root_i] = root_j
            return True

        for r in range(m):
            for c in range(n):
                idx = r * n + c
                
                if r > 0 and grid[r][c] == grid[r - 1][c]:
                    if not union(idx, (r - 1) * n + c):
                        return True
                        
                if c > 0 and grid[r][c] == grid[r][c - 1]:
                    if not union(idx, r * n + (c - 1)):
                        return True
                        
        return False
```
