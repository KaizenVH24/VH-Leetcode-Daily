# Intuition

A rhombus in the grid looks like a diamond shape whose corners lie on grid cells.  
The sum we need is only the **border of the rhombus**, not the entire area.

Every rhombus can be defined by:
- a **center cell**
- a **size** (distance from the center to the four corners)

When the size is `0`, the rhombus is just a single cell.  
For larger sizes, the rhombus has four edges:
- top → right
- right → bottom
- bottom → left
- left → top

So for each cell we try to expand possible rhombus sizes while staying inside the grid and compute the border sum.

Since we only need the **three largest distinct sums**, we store the sums in a set and finally return the top three values.

---

# Approach

1. Get the dimensions of the grid.
2. Use a set to store rhombus sums so duplicates are automatically removed.
3. For every cell `(r, c)`:
   - Add the value of the cell itself (size `0` rhombus).
4. Expand the rhombus size gradually:
   - Check whether the four corners stay inside the grid.
   - If they go outside the grid, stop increasing the size.
5. For each valid size, compute the border sum by walking along the four edges of the rhombus.
6. Add the computed sum to the set.
7. After processing all centers and sizes, sort the set in descending order and return the top three values.

---

# Complexity

- **Time complexity:**  
  `O(m * n * min(m, n))`  
  For each cell we attempt possible rhombus sizes until the grid boundary is reached.

- **Space complexity:**  
  `O(k)`  
  Where `k` is the number of distinct rhombus sums stored.

---

# Code

```python
class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        
        m, n = len(grid), len(grid[0])
        res = set()

        for r in range(m):
            for c in range(n):
                res.add(grid[r][c])

                size = 1
                while True:
                    if r - size < 0 or r + size >= m or c - size < 0 or c + size >= n:
                        break

                    s = 0

                    # top - right
                    x, y = r - size, c
                    for i in range(size):
                        s += grid[x + i][y + i]

                    # right - bottom
                    x, y = r, c + size
                    for i in range(size):
                        s += grid[x + i][y - i]

                    # bottom - left
                    x, y = r + size, c
                    for i in range(size):
                        s += grid[x - i][y - i]

                    # left - top
                    x, y = r, c - size
                    for i in range(size):
                        s += grid[x - i][y + i]

                    res.add(s)
                    size += 1

        return sorted(res, reverse=True)[:3]
```
