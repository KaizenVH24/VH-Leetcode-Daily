### 3130. Find All Possible Stable Binary Arrays II

# Intuition

We need to build binary arrays that contain exactly `zero` number of `0`s and `one` number of `1`s.  
The restriction says we cannot have more than `limit` identical elements consecutively. In other words, a run of `0`s or `1`s cannot be longer than `limit`.

While constructing the array, the last element matters because it determines whether we are extending a sequence of `0`s or `1`s.  
So it makes sense to keep track of two cases separately:

- arrays that end with `0`
- arrays that end with `1`

Using this idea, we can count valid arrays step by step with dynamic programming.

---

# Approach

We use two DP tables:

- `dp0[i][j]` → number of valid arrays using `i` zeros and `j` ones that end with `0`
- `dp1[i][j]` → number of valid arrays using `i` zeros and `j` ones that end with `1`

First we initialize the base cases where only zeros or only ones are used, but only up to `limit` length since longer runs are not allowed.

Then we fill the DP tables:

- To end with `0`, we add a zero to arrays that previously ended with `0` or `1`.
- To end with `1`, we add a one to arrays that previously ended with `0` or `1`.

If adding the element causes the number of consecutive `0`s or `1`s to exceed `limit`, we subtract those invalid cases from the count.

Finally, the result is the total number of arrays that use all zeros and ones, regardless of whether they end with `0` or `1`.

---

# Complexity

- **Time complexity:**  
  $$O(zero \times one)$$  
  Every state `(i, j)` is computed once.

- **Space complexity:**  
  $$O(zero \times one)$$  
  Two DP tables of size `(zero+1) × (one+1)` are maintained.

---

# Code

```python
class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:

        MOD = 10**9 + 7
        
        dp0 = [[0] * (one + 1) for _ in range(zero + 1)]
        dp1 = [[0] * (one + 1) for _ in range(zero + 1)]
        
        for i in range(1, min(zero, limit) + 1):
            dp0[i][0] = 1
        for j in range(1, min(one, limit) + 1):
            dp1[0][j] = 1
            
        for i in range(1, zero + 1):
            for j in range(1, one + 1):
                dp0[i][j] = (dp0[i-1][j] + dp1[i-1][j]) % MOD
                if i > limit:
                    dp0[i][j] = (dp0[i][j] - dp1[i - limit - 1][j]) % MOD
                
                dp1[i][j] = (dp0[i][j-1] + dp1[i][j-1]) % MOD
                if j > limit:
                    dp1[i][j] = (dp1[i][j] - dp0[i][j - limit - 1]) % MOD
                    
        return (dp0[zero][one] + dp1[zero][one]) % MOD
```
