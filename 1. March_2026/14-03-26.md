# Intuition

A happy string can only contain the characters `a`, `b`, and `c`, and no two adjacent characters can be the same.  

If we think about building the string step by step:
- For the first position, we have **3 choices** (`a`, `b`, `c`).
- For every next position, we only have **2 choices** because we cannot repeat the previous character.

So the total number of happy strings of length `n` is:

`3 * 2^(n-1)`

Instead of generating all possible strings and sorting them, we can determine the **k-th string directly** by skipping groups of strings based on how many combinations each prefix can generate.

---

# Approach

1. First calculate the total number of happy strings of length `n`.  
   If `k` is larger than this number, return an empty string since the k-th string does not exist.

2. Build the answer one character at a time.

3. At each position, determine how many valid strings can be formed if we fix a certain character at that position.  
   This number is `2^(remaining length)`.

4. Try characters in lexicographical order (`a`, `b`, `c`):
   - Skip the character if it is the same as the previous one.
   - If `k` is greater than the number of strings starting with that prefix, subtract that block from `k` and move to the next character.
   - Otherwise, select that character and move to the next position.

5. Continue until the string reaches length `n`.

---

# Complexity

**Time complexity:**  
`O(n)`  
We construct the string one character at a time.

**Space complexity:**  
`O(1)`  
Only a few variables are used apart from the result string.

---

# Code

```python
class Solution:
    def getHappyString(self, n: int, k: int) -> str:
        
        total = 3 * (1 << (n - 1))
        
        if k > total:
            return ""
        
        chars = ['a', 'b', 'c']
        result = []
        prev = ''
        
        for i in range(n):
            block = 1 << (n - i - 1)
            
            for c in chars:
                if c == prev:
                    continue
                
                if k > block:
                    k -= block
                else:
                    result.append(c)
                    prev = c
                    break
        
        return "".join(result)
```
