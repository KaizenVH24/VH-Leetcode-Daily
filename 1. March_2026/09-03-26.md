### 3129. Find All Possible Stable Binary Arrays I

# Intuition

We need to build binary arrays that use exactly `zero` zeros and `one` ones.  
The tricky part is the restriction: no subarray longer than `limit` can contain only one type of element. In simpler terms, we cannot have more than `limit` consecutive `0`s or more than `limit` consecutive `1`s.

If we try to construct the array step by step, the last element we place matters. For example, if the last element is `0`, then we must be careful not to extend a run of `0`s beyond the allowed limit. The same logic applies to `1`s.

Because of this, it helps to track two states:
- arrays that end with `0`
- arrays that end with `1`

Using dynamic programming, we count how many valid arrays can be formed for every possible number of zeros and ones used so far.

---

# Approach

We maintain two DP tables:

- `dp0[i][j]`: number of valid arrays that use `i` zeros and `j` ones and end with `0`
- `dp1[i][j]`: number of valid arrays that use `i` zeros and `j` ones and end with `1`

Initialization:
- Arrays consisting only of zeros (up to `limit`) are valid.
- Arrays consisting only of ones (up to `limit`) are also valid.

Transition:
- To end with `0`, the previous element could have been `0` or `1`, but we must ensure the sequence of zeros does not exceed `limit`.
- Similarly, to end with `1`, we extend sequences while ensuring we do not exceed `limit`.

If adding a new element would cause the consecutive count to exceed `limit`, we subtract those invalid cases from the count.

At the end, the answer is the sum of arrays ending with `0` and arrays ending with `1` using all zeros and ones.

---

# Complexity

- **Time complexity:**  
  $$O(zero \times one)$$  
  We fill a DP table with `(zero + 1) × (one + 1)` states.

- **Space complexity:**  
  $$O(zero \times one)$$  
  Two DP tables are used to store intermediate results.

---

# Code

```python
class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:

        MOD = 10**9 + 7
        
        dp0 = [[0] * (one + 1) for i in range(zero + 1)]
        dp1 = [[0] * (one + 1) for j in range(zero + 1)]
        
        for i in range(1, min(zero, limit) + 1):
            dp0[i][0] = 1
        for j in range(1, min(one, limit) + 1):
            dp1[0][j] = 1
            
        for i in range(1, zero + 1):
            for j in range(1, one + 1):

                dp0[i][j] = (dp0[i-1][j] + dp1[i-1][j]) % MOD

                if i > limit:
                    dp0[i][j] = (dp0[i][j] - dp1[i - limit - 1][j] + MOD) % MOD

                dp1[i][j] = (dp0[i][j-1] + dp1[i][j-1]) % MOD

                if j > limit:
                    dp1[i][j] = (dp1[i][j] - dp0[i][j - limit - 1] + MOD) % MOD
                    
        return (dp0[zero][one] + dp1[zero][one]) % MOD
```
