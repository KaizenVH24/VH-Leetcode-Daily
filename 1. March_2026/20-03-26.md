# Intuition

For every k x k submatrix, we need the minimum absolute difference between any two **distinct values**.  
A direct thought is to check all pairs inside each submatrix, but that would be too slow.

A better idea is: if we sort all unique values in the submatrix, the minimum difference will always be between **adjacent elements** in the sorted order. So instead of checking all pairs, we just need to sort and compare neighbors.

---

# Approach

1. Iterate over all possible k x k submatrices using top-left corner `(i, j)`.

2. For each submatrix:
   - Collect all values into a set (to remove duplicates).
   - Convert the set to a sorted list.

3. If there is only one unique value, answer is `0` (no distinct pair exists).

4. Otherwise:
   - Traverse the sorted list
   - Compute minimum difference between consecutive elements

5. Store the result for each submatrix.

---

# Complexity

- Time complexity: $$O((m \cdot n \cdot k^2) + (k^2 \log k))$$  
  (Collecting elements + sorting for each submatrix)

- Space complexity: $$O(k^2)$$  

---

# Code

```python
class Solution:
    def minAbsDiff(self, grid: List[List[int]], k: int) -> List[List[int]]:
        
        m, n = len(grid), len(grid[0])
        ans = []

        for i in range(m - k + 1):
            row = []
            for j in range(n - k + 1):
                vals = set()
                for x in range(i, i + k):
                    for y in range(j, j + k):
                        vals.add(grid[x][y])
                
                vals = sorted(vals)
                
                if len(vals) <= 1:
                    row.append(0)
                else:
                    min_diff = float('inf')
                    for t in range(1, len(vals)):
                        min_diff = min(min_diff, vals[t] - vals[t-1])
                    row.append(min_diff)
            
            ans.append(row)
        
        return ans
```
