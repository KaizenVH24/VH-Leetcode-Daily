# Intuition

If we directly update every element whenever `addAll` or `multAll` is called, the time complexity becomes too large. Since there can be up to \(10^5\) operations, repeatedly modifying the whole sequence would lead to a time limit exceeded error.

A better idea is to notice that every value in the sequence is affected by the same transformation. If the current transformation applied to all elements is:

value = value * mul + add

then instead of updating each element individually, we can simply keep track of the global multiplication (`mul`) and addition (`add`).  

When a new value is appended, we store it in such a way that when the current transformation is applied later, it produces the correct value.

---

# Approach

1. Maintain two variables:
   - `mul` → the cumulative multiplication applied to the sequence.
   - `add` → the cumulative addition applied to the sequence.

2. When `addAll(inc)` is called, simply update `add`.

3. When `multAll(m)` is called:
   - Multiply both `mul` and `add` by `m` because all values are scaled.

4. When `append(val)` is called:
   - Reverse the current transformation so the stored value remains consistent with future operations.
   - This requires using a modular inverse of `mul`.

5. When `getIndex(idx)` is called:
   - If the index exists, apply the current transformation to the stored value and return the result modulo \(10^9 + 7\).
   - Otherwise return `-1`.

This way, every operation can be handled in constant time.

---

# Complexity

- **Time complexity:**  
  \(O(1)\) per operation (`append`, `addAll`, `multAll`, `getIndex`).

- **Space complexity:**  
  \(O(n)\) for storing the appended elements.

---

# Code

```python
class Fancy:

    def __init__(self):
        self.MOD = 10**9 + 7
        self.seq = []
        self.mul = 1
        self.add = 0

    def append(self, val: int) -> None:
        val = (val - self.add) % self.MOD
        val = val * pow(self.mul, -1, self.MOD) % self.MOD
        self.seq.append(val)

    def addAll(self, inc: int) -> None:
        self.add = (self.add + inc) % self.MOD

    def multAll(self, m: int) -> None:
        self.mul = (self.mul * m) % self.MOD
        self.add = (self.add * m) % self.MOD

    def getIndex(self, idx: int) -> int:
        if idx >= len(self.seq):
            return -1
        
        return (self.seq[idx] * self.mul + self.add) % self.MOD

```
