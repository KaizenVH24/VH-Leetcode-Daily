# Intuition

Since we are allowed to rearrange the columns, the exact column order doesn’t matter. What really matters is how many consecutive `1`s we can stack vertically in each column.

So instead of thinking in terms of the original matrix, we convert each row into a form where each cell represents the height of consecutive `1`s ending at that row.

Once we have these heights, each row can be treated like a histogram.  
If we rearrange the columns optimally, we would place taller columns together to form the largest possible rectangle.

---

# Approach

1. Traverse the matrix and build heights:
   - For each cell, if it is `1`, add the value from the cell directly above it.
   - This gives the number of consecutive `1`s ending at that cell.

2. For each row:
   - Sort the heights in descending order.
   - This simulates rearranging columns to group taller columns together.

3. For each position in the sorted row:
   - Treat it as the right boundary of a rectangle.
   - Width = number of columns used (`j + 1`)
   - Height = current value
   - Calculate area = height × width and update the maximum.

4. Return the maximum area found.

---

# Complexity

- **Time complexity:**  
  `O(m * n log n)`  
  Building heights takes `O(m * n)` and sorting each row takes `O(n log n)`.

- **Space complexity:**  
  `O(1)`  
  The matrix is modified in-place, so no extra space is required.

---

# Code

```python
class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:

        m, n = len(matrix), len(matrix[0])
        
        # Step 1: build heights
        for i in range(1, m):
            for j in range(n):
                if matrix[i][j] == 1:
                    matrix[i][j] += matrix[i-1][j]
        
        max_area = 0
        
        # Step 2: for each row sort heights descending
        for row in matrix:
            row.sort(reverse=True)
            
            # Step 3: calculate area
            for j in range(n):
                height = row[j]
                width = j + 1
                max_area = max(max_area, height * width)
        
        return max_area
```
