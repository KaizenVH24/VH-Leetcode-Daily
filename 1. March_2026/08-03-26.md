### 1980. Find Unique Binary String

---

# Intuition

We are given `n` binary strings and each of them has length `n`. Since all of them are unique, there are still many possible binary strings of length `n` that are not present in the list.

One reliable way to guarantee a different string is to look at the diagonal characters of the input. If we take the `i-th` character of the `i-th` string and flip it, the resulting string will differ from that string at least at that position.

Doing this for every index ensures that the constructed string will be different from every string in the list.

---

# Approach

Create a new result string one character at a time.

For every index `i`:
- Check the `i-th` character of `nums[i]`
- If it is `'0'`, append `'1'`
- If it is `'1'`, append `'0'`

This way, the new string differs from the `i-th` string exactly at index `i`. Because of this, it cannot match any of the strings in the input list.

Finally, join all characters to form the resulting binary string.

---

# Complexity

- **Time complexity:**  
  $$O(n)$$  
  We iterate through the list once.

- **Space complexity:**  
  $$O(n)$$  
  The result string stores `n` characters.

---

# Code
```python
class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:

        result = []
        
        for i in range(len(nums)):
            if nums[i][i] == '0':
                result.append('1')
            else:
                result.append('0')
        
        return "".join(result)
```
