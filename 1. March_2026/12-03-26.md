### 3600. Maximize Spanning Tree Stability with Upgrades

# Intuition

The stability of the spanning tree is defined as the minimum strength among all edges included in the tree.  
So instead of trying to build the tree directly, it helps to think about the problem in reverse:  

What is the largest value `x` such that we can still build a spanning tree where every chosen edge has strength at least `x`?

Mandatory edges must always be included in the tree, so if any mandatory edge already has strength smaller than `x`, that candidate value cannot work.  
Optional edges give more flexibility because they can either be used as they are or upgraded once (doubling their strength).

Since the stability value we are searching for has an upper bound, we can try possible values and check if a spanning tree can be formed under those constraints.

---

# Approach

We use **binary search** on the stability value.

For a candidate value `x`, we check whether it is possible to build a spanning tree where every edge has strength at least `x`.

To test this:

1. Use a **Disjoint Set Union (Union-Find)** structure to build the tree.
2. First include all mandatory edges.
   - If any mandatory edge has strength smaller than `x`, it immediately fails.
   - If these edges form a cycle, a spanning tree is impossible.
3. Process optional edges:
   - If an edge already has strength ≥ `x`, it can be used normally.
   - If doubling its strength makes it ≥ `x`, it can be used with an upgrade (as long as we still have upgrades left).
4. Continue joining components until either:
   - We connect all `n` nodes using `n-1` edges → success
   - Or we run out of edges/upgrades → failure

Binary search keeps increasing the candidate value as long as it remains possible.

---

# Complexity

- **Time complexity:**  
  $$O(E \log S)$$  
  where `E` is the number of edges and `S` is the possible strength range.  
  Each binary search step performs union operations over the edges.

- **Space complexity:**  
  $$O(N)$$  
  The Union-Find structure stores parent and rank arrays for `n` nodes.

---

# Code
```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0]*n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        pa, pb = self.find(a), self.find(b)
        if pa == pb:
            return False
        if self.rank[pa] < self.rank[pb]:
            pa, pb = pb, pa
        self.parent[pb] = pa
        if self.rank[pa] == self.rank[pb]:
            self.rank[pa] += 1
        return True

class Solution:
    def maxStability(self, n: int, edges: List[List[int]], k: int) -> int:

        must_edges = []
        optional_edges = []

        for u, v, s, m in edges:
            if m == 1:
                must_edges.append((u, v, s))
            else:
                optional_edges.append((u, v, s))

        def can(x):
            dsu = DSU(n)
            upgrades = 0
            used = 0

            for u, v, s in must_edges:
                if s < x:
                    return False
                if not dsu.union(u, v):
                    return False
                used += 1

            good = []
            need_upgrade = []

            for u, v, s in optional_edges:
                if s >= x:
                    good.append((u, v))
                elif 2*s >= x:
                    need_upgrade.append((u, v))

            for u, v in good:
                if dsu.union(u, v):
                    used += 1

            for u, v in need_upgrade:
                if used == n-1:
                    break
                if upgrades == k:
                    break
                if dsu.union(u, v):
                    upgrades += 1
                    used += 1

            return used == n-1

        lo, hi = 1, 2*10**5
        ans = -1

        while lo <= hi:
            mid = (lo + hi)//2
            if can(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1

        return ans
```
