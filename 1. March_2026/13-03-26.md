# Intuition

Each worker takes more time for every additional unit of height they remove.  
For a worker with time `t`, removing `x` units of height takes:

`t + 2t + 3t + ... + xt`

This can be simplified using the sum of the first `x` natural numbers:

`t * (x * (x + 1) / 2)`

Since all workers operate simultaneously, the total time required depends on the maximum time any worker spends. Instead of directly assigning work to workers, we can guess a time `T` and check how much height all workers together can reduce within that time.

If the workers can reduce at least `mountainHeight` within `T` seconds, then `T` is enough. Otherwise, we need more time. This makes it suitable to use **binary search on time**.

---

# Approach

1. Use binary search to find the minimum time required.
2. The search range is from `0` to the maximum possible time if one worker removes the whole mountain.
3. For a guessed time `T`, calculate how much height each worker can reduce.
4. From the inequality  
   `t * x * (x + 1) / 2 ≤ T`,  
   compute the maximum `x` each worker can remove.
5. Add the heights removed by all workers.
6. If the total is greater than or equal to `mountainHeight`, the time is sufficient, so try a smaller value.
7. Otherwise, increase the time.
8. Continue until the smallest valid time is found.

---

# Complexity

**Time complexity:**  
`O(n log(maxTime))`  
Binary search is performed on the time range, and each check iterates through all workers.

**Space complexity:**  
`O(1)`  
Only a few variables are used.

---

# Code

```python
import math

class Solution:
    def minNumberOfSeconds(self, mountainHeight: int, workerTimes: List[int]) -> int:

        def can_finish(time):
            total = 0
            
            for t in workerTimes:
                val = (2 * time) // t
                x = int((math.sqrt(1 + 4 * val) - 1) // 2)
                total += x
                
                if total >= mountainHeight:
                    return True
            
            return False
        
        left = 0
        right = max(workerTimes) * mountainHeight * (mountainHeight + 1) // 2
        
        ans = right
        
        while left <= right:
            mid = (left + right) // 2
            
            if can_finish(mid):
                ans = mid
                right = mid - 1
            else:
                left = mid + 1
        
        return ans
```
