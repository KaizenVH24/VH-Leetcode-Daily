# Intuition

Every valid submatrix must include the top-left cell `(0, 0)`.  
So instead of thinking about all possible submatrices, we only need to consider rectangles that start at `(0, 0)` and end at some `(i, j)`.

That means each cell `(i, j)` represents exactly one submatrix: the rectangle from `(0, 0)` to `(i, j)`.

If we can quickly compute the sum of this rectangle, we just check whether it is ≤ `k`.

This is a perfect use case for **2D prefix sums**.

---

# Approach

1. Traverse the grid and convert it into a prefix sum matrix (in-place).
2. For each cell `(i, j)`:
   - Add the value from the top (`i-1, j`) if it exists.
   - Add the value from the left (`i, j-1`) if it exists.
   - Subtract the top-left diagonal (`i-1, j-1`) to avoid double counting.
3. Now `grid[i][j]` stores the sum of the submatrix from `(0,0)` to `(i,j)`.
4. If this value is ≤ `k`, increment the count.
5. Return the total count.

---

# Complexity

- **Time complexity:**  
  `O(m * n)`  
  We process each cell exactly once.

- **Space complexity:**  
  `O(1)`  
  We reuse the input grid to store prefix sums.

---

# Code

```python
class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:

        m, n = len(grid), len(grid[0])
        count = 0
        
        for i in range(m):
            for j in range(n):
                if i > 0:
                    grid[i][j] += grid[i-1][j]
                    
                if j > 0:
                    grid[i][j] += grid[i][j-1]

                if i > 0 and j > 0:
                    grid[i][j] -= grid[i-1][j-1]

                if grid[i][j] <= k:
                    count += 1
        
        return count
```
