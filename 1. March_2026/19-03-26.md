# Intuition

At first glance, this looks like a typical “count submatrices” problem, which usually means heavy 2D prefix sum + hashmap work. But the constraint that every valid submatrix **must include (0,0)** simplifies things a lot.

Because of that, every submatrix we care about is just a prefix rectangle from `(0,0)` to `(i,j)`. So instead of checking all possible submatrices, we only need to evaluate each `(i,j)` once.

To handle equal counts of `X` and `Y`, we map:
- `X → +1`
- `Y → -1`
- `.` → 0

Now the problem reduces to checking whether the prefix sum is `0` (meaning equal `X` and `Y`).  
Additionally, we need to ensure there is at least one `X`, so we track that separately.

---

# Approach

1. Create two 2D prefix matrices:
   - `sum_grid` → stores balance of `X` and `Y`
   - `x_count` → stores count of `X`

2. Traverse the grid and build prefix sums using the standard formula:
    ```prefix[i][j] = current + top + left - diagonal```

3. For each cell `(i, j)`:
- Convert the character into a value (`+1`, `-1`, or `0`)
- Update both prefix matrices

4. After building the prefix matrices, iterate through all `(i, j)`:
- If `sum_grid[i][j] == 0` → equal `X` and `Y`
- If `x_count[i][j] > 0` → at least one `X`
- Count such cells

---

# Complexity

- Time complexity: $$O(m \times n)$$  
- Space complexity: $$O(m \times n)$$  

---

# Code

```python
class Solution:
 def numberOfSubmatrices(self, grid: List[List[str]]) -> int:
 
     m, n = len(grid), len(grid[0])

     sum_grid = [[0]*n for i in range(m)]
     x_count = [[0]*n for i in range(m)]

     for i in range(m):
         for j in range(n):
             val = 0
             if grid[i][j] == 'X':
                 val = 1
             elif grid[i][j] == 'Y':
                 val = -1

             sum_grid[i][j] = val
             x_count[i][j] = 1 if grid[i][j] == 'X' else 0

             if i > 0:
                 sum_grid[i][j] += sum_grid[i-1][j]
                 x_count[i][j] += x_count[i-1][j]

             if j > 0:
                 sum_grid[i][j] += sum_grid[i][j-1]
                 x_count[i][j] += x_count[i][j-1]

             if i > 0 and j > 0:
                 sum_grid[i][j] -= sum_grid[i-1][j-1]
                 x_count[i][j] -= x_count[i-1][j-1]

     ans = 0

     for i in range(m):
         for j in range(n):
             if sum_grid[i][j] == 0 and x_count[i][j] > 0:
                 ans += 1

     return ans
```
