# Intuition
Since both `A` and `B` are permutations of numbers from $1$ to $n$, every number will appear exactly once in `A` and exactly once in `B`. 

As we iterate through both arrays simultaneously from left to right, we can keep a running tally of how many times we've seen each number. Because a number only appears twice in total across both arrays, a number becomes "common" to both prefixes the exact moment its count reaches `2`. 

# Approach
1.  **Track Frequencies:** Create a `seen` array of size $n + 1$ (since the numbers go from $1$ to $n$) initialized to `0`. This will track how many times we have encountered each number so far.
2.  **Initialize Variables:** Create a running counter `common_count = 0` to track the number of elements that have appeared in both prefixes, and an empty list `C` to store our results.
3.  **Iterate and Update:** Loop through the arrays using an index `i` from $0$ to $n-1$:
    * Increment the count for the number at `A[i]`. If its count hits `2`, it means we've now seen it in both arrays, so we increment `common_count`.
    * Increment the count for the number at `B[i]`. If its count hits `2`, we again increment `common_count`.
    * Append the current `common_count` to our result array `C`.
4.  **Return Result:** After the loop finishes, `C` will contain the prefix common counts for every index.

*(Note: If `A[i]` and `B[i]` are the same number, the logic still works perfectly. It will be incremented to `1` during the `A[i]` check, and then immediately to `2` during the `B[i]` check, properly registering as a common number).*

# Complexity
- **Time complexity:** $\mathcal{O}(N)$
  Where $N$ is the length of the arrays. We iterate through the arrays exactly once. Array lookups and updates take $\mathcal{O}(1)$ time.
- **Space complexity:** $\mathcal{O}(N)$
  We use a `seen` frequency array of size $N + 1$ and a result array `C` of size $N$. 

# Code
```python3 []
class Solution:
    def findThePrefixCommonArray(self, A: list[int], B: list[int]) -> list[int]:
        n = len(A)
        seen = [0] * (n + 1)
        common_count = 0
        C = []
        
        for i in range(n):
            # Process element from A
            seen[A[i]] += 1
            if seen[A[i]] == 2:
                common_count += 1
                
            # Process element from B
            seen[B[i]] += 1
            if seen[B[i]] == 2:
                common_count += 1
                
            # Record the common count for the current prefix
            C.append(common_count)
            
        return C
