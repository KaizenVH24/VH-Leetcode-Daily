# Intuition
The problem asks us to break down a list of numbers into a flat list of their individual digits. In Python, the most intuitive and readable way to separate an integer into digits is to convert it into a string. Since strings are iterable, we can easily loop through each character, convert it back into an integer, and add it to our final result.

# Approach
1. We can use a clean and highly optimized Python feature called a **list comprehension**.
2. We iterate through each `num` in the given `nums` array.
3. For each `num`, we convert it to a string using `str(num)`.
4. We then iterate through each character (`digit`) in that string.
5. Finally, we convert that character back to an integer `int(digit)` and place it in our new list. 

# Complexity
- Time complexity:
$$O(S)$$
Where $S$ is the total number of digits across all numbers in the array. Converting numbers to strings and iterating over their characters takes time strictly proportional to the total number of digits we process.

- Space complexity:
$$O(S)$$
We create an output array that will exactly hold $S$ elements (all the separated digits). 

# Code
```python3 []
class Solution:
    def separateDigits(self, nums: list[int]) -> list[int]:
        # A flat list comprehension to iterate through numbers, then their digits
        return [int(digit) for num in nums for digit in str(num)]
