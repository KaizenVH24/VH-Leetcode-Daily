# Intuition
Calculating the rotation function $F(k)$ from scratch for every single rotation would require an $O(N^2)$ time complexity, which will result in a Time Limit Exceeded (TLE) error given the constraint $N \le 10^5$. 

Instead, we can look for a mathematical relationship between $F(k-1)$ and $F(k)$. 
Let's use an array `[A, B, C, D]` where $n = 4$:
- $F(0) = 0A + 1B + 2C + 3D$
- $F(1) = 1A + 2B + 3C + 0D$

If we subtract $F(0)$ from $F(1)$, we get:
$F(1) - F(0) = A + B + C - 3D$

Notice that $A + B + C$ is almost the sum of the entire array. If we add $D$ to it, it becomes exactly the sum of the array. So, we can rewrite the equation as:
$F(1) - F(0) = (A + B + C + D) - 4D$
$F(1) = F(0) + \text{Sum} - n \times D$

Generalizing this pattern for any $k$:
$F(k) = F(k-1) + \text{Sum} - n \times \text{nums}[n - k]$

This means we only need to calculate $F(0)$ the hard way, and then we can find all subsequent $F(k)$ values in $O(1)$ time each.

# Approach
1. Calculate the total `sum` of the `nums` array.
2. Calculate the initial value `F_0` using the formula $F(0) = \sum i \times \text{nums}[i]$.
3. Set a variable `max_val` to keep track of the highest function value, initially set to `F_0`.
4. Set a variable `current_F` to keep track of the current rotation's value, initially set to `F_0`.
5. Loop $k$ from $1$ to $n-1$:
   - Calculate the new `current_F` using the derived formula: `current_F = current_F + sum - n * nums[n - k]`.
   - Update `max_val` if `current_F` is strictly greater.
6. Return `max_val`.

# Complexity
- Time complexity:
$$O(N)$$
We iterate through the array a few times: once to find the sum, once to find $F(0)$, and once to compute the values of $F(1)$ through $F(n-1)$. All are linear operations.

- Space complexity:
$$O(1)$$
We only use a few integer variables (`total_sum`, `current_F`, `max_val`, `n`) to store intermediate values.

class Solution:
    def maxRotateFunction(self, nums: list[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0
            
        total_sum = sum(nums)
        
        # Calculate initial F(0)
        current_F = 0
        for i in range(n):
            current_F += i * nums[i]
            
        max_val = current_F
        
        # Calculate F(k) based on F(k-1)
        for k in range(1, n):
            current_F = current_F + total_sum - (n * nums[n - k])
            max_val = max(max_val, current_F)
            
        return max_val
