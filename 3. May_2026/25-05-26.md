# Intuition
A naive approach would be to start at index `0` and recursively or iteratively check every single possible jump between `minJump` and `maxJump`. However, if `maxJump - minJump` is very large, this results in a Time Limit Exceeded (TLE) error with $O(N \times \text{jump range})$ complexity.

Instead of looking *forward* from where we are, we can look *backward* from where we want to land. For any given index `i`, we can reach it if `s[i] == '0'` AND there is at least one already-reachable index within the window `[i - maxJump, i - minJump]`. 

To do this efficiently, we can use a **Sliding Window** technique combined with Dynamic Programming. We will keep a running count of how many "reachable" indices exist within our valid jump window. As we move our current index `i` forward, we simply update this count by adding the index that just entered the back of the window and subtracting the index that just fell out of the front.

# Approach
1.  **Early Exit:** If the last character of the string `s` is `'1'`, it is physically impossible to end there. Return `False` immediately.
2.  **Initialize DP:** Create a boolean array `dp` of size $N$, where `dp[i]` tracks whether index `i` is reachable. Set `dp[0] = True`.
3.  **Sliding Window Variable:** Initialize a counter `active = 0`. This will track the number of reachable indices that can currently jump to our position `i`.
4.  **Iterate:** Loop `i` from `1` to $N - 1$:
    * **Window Enters:** When `i >= minJump`, the index `i - minJump` comes into range. If `dp[i - minJump]` is `True`, we increment `active`.
    * **Window Exits:** When `i > maxJump`, the index `i - maxJump - 1` falls out of range. If `dp[i - maxJump - 1]` was `True`, we decrement `active`.
    * **Update DP:** If the current character `s[i]` is `'0'` and we have at least one active reachable position behind us (`active > 0`), we set `dp[i] = True`.
5.  **Result:** Return `dp[-1]`, which tells us if the final index is reachable.

# Complexity
- **Time complexity:** $\mathcal{O}(N)$
  Where $N$ is the length of the string `s`. We iterate through the string exactly once, performing constant-time $\mathcal{O}(1)$ additions and subtractions to our `active` window counter.
- **Space complexity:** $\mathcal{O}(N)$
  We allocate a boolean `dp` array of length $N$ to store the reachable state of every index.

class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        # We can never land on a '1'
        if s[-1] == '1':
            return False
            
        n = len(s)
        dp = [False] * n
        dp[0] = True
        
        # Tracks the number of reachable indices within the valid jump window
        active = 0
        
        for i in range(1, n):
            # 1. Add the index that just entered our valid jump window
            if i >= minJump and dp[i - minJump]:
                active += 1
                
            # 2. Remove the index that just fell out of our valid jump window
            if i > maxJump and dp[i - maxJump - 1]:
                active -= 1
                
            # 3. If we can land here and there's at least one valid jump origin
            if s[i] == '0' and active > 0:
                dp[i] = True
                
        return dp[-1]
