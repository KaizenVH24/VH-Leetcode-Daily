# Intuition
The problem asks for the maximum number of jumps to reach the end of the array under specific jump constraints. Since we are moving strictly from left to right and want to find an optimal sequence (maximum jumps) built upon smaller subproblems, this is a perfect fit for Dynamic Programming. 

For any index `j`, the maximum jumps it takes to reach there depends entirely on the maximum jumps it took to reach a valid previous index `i`.

# Approach
1.  **Initialize DP Array:** Create an array `dp` of size `n` where `dp[i]` represents the maximum number of jumps required to reach index `i`. Initialize all elements to `-1` to represent that an index is currently unreachable.
2.  **Base Case:** We start at index 0, so it takes `0` jumps to reach there. Set `dp[0] = 0`.
3.  **Nested Iteration:** * Use an outer loop with pointer `j` to represent the destination index, iterating from `1` to `n - 1`.
    * Use an inner loop with pointer `i` to represent the starting index of the jump, iterating from `0` to `j - 1`.
4.  **Validation and Update:** For every pair `(i, j)`, check if two conditions are met:
    * Index `i` is reachable (`dp[i] != -1`).
    * The jump is valid (`abs(nums[j] - nums[i]) <= target`).
    * If both are true, update `dp[j]` to be the maximum between its current value and `dp[i] + 1`.
5.  **Result:** After filling out the table, `dp[n - 1]` will contain the maximum jumps to the last index. If it remains `-1`, it means the last index is completely unreachable.

# Complexity
- Time complexity:
$$O(N^2)$$
Where $N$ is the length of the `nums` array. We have a nested loop where $j$ goes up to $N$ and $i$ goes up to $j$. This results in roughly $N^2 / 2$ operations. Given the constraint $N \le 1000$, $N^2 \approx 1,000,000$, which will execute well within the time limit.

- Space complexity:
$$O(N)$$
We use a 1D `dp` array of size $N$ to store the maximum jumps for each index.

class Solution:
    def maximumJumps(self, nums: list[int], target: int) -> int:
        n = len(nums)
        # dp[i] stores the max jumps to reach index i. -1 means unreachable.
        dp = [-1] * n
        dp[0] = 0
        
        for j in range(1, n):
            for i in range(j):
                # If index i is reachable and the jump is within the target difference
                if dp[i] != -1 and abs(nums[j] - nums[i]) <= target:
                    dp[j] = max(dp[j], dp[i] + 1)
                    
        return dp[-1]
