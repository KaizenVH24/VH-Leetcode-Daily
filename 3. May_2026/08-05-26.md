# Intuition
This problem asks for the minimum number of jumps to reach the end of an array, which is a classic indicator for finding the shortest path using Breadth-First Search (BFS). 

The graph consists of two types of edges:
1. **Adjacent edges**: You can always move to `i - 1` or `i + 1`.
2. **Teleportation edges**: If you land on a prime number $p$, you can jump to *any* index holding a multiple of $p$.

A naive approach of iterating through all indices to find multiples of $p$ would result in an $O(N^2)$ Time Limit Exceeded (TLE) error. To optimize this, we can pre-group indices by their values and use the Sieve of Eratosthenes to quickly identify primes. Furthermore, since BFS guarantees the shortest path, once we jump to all indices holding a specific value, we can safely "clear" that value's bucket so we never redundantly process it again.

# Approach
1.  **Sieve of Eratosthenes**: First, find the maximum value in the array (`max_val`). Use the Sieve to precompute prime numbers up to `max_val` in $O(M \log \log M)$ time.
2.  **Value-to-Index Mapping**: Create an array of lists `val_to_idx` where `val_to_idx[v]` contains all the indices $i$ where `nums[i] == v`. This allows us to jump to targets instantly without scanning the array.
3.  **Breadth-First Search (BFS)**:
    * Initialize a `queue` starting with index `0`.
    * Track visited indices to avoid loops, and track visited primes so we only trigger a prime's massive teleportation wave exactly once.
    * For each index popped from the queue, first attempt the standard adjacent jumps (`i - 1` and `i + 1`).
    * If `nums[i]` is prime and hasn't been activated yet, activate it: iterate through all multiples of `nums[i]` up to `max_val`. For each multiple, grab all its indices from `val_to_idx` and push them to the queue.
    * **Crucial Optimization**: After pushing the indices for a multiple, explicitly clear its list (`val_to_idx[multiple].clear()`). If another prime targets this same multiple later, we skip it instantly because those indices have already been reached in the fewest jumps possible.
4.  **Early Exit**: Check if the target index `n - 1` is reached *before* adding it to the queue to save an entire level of BFS processing.

# Complexity
- Time complexity:
$$O(N + M \log \log M)$$
Where $N$ is the length of `nums` and $M$ is the maximum value in `nums`. Building the Sieve takes $O(M \log \log M)$. Grouping the indices takes $O(N)$. Because of the `clear()` optimization, every index is added to the BFS queue at most once, and every element in `val_to_idx` is iterated exactly once across the entire algorithm. Thus, the BFS strictly runs in $O(N + M \log \log M)$.

- Space complexity:
$$O(N + M)$$
We use $O(M)$ space for the `is_prime` array and the `val_to_idx` map (which holds $N$ total integers). The BFS queue and `visited` arrays take an additional $O(N)$ space.

from collections import deque

class Solution:
    def minJumps(self, nums: list[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0
            
        max_val = max(nums)
        
        # Step 1: Sieve of Eratosthenes to identify primes up to max_val
        is_prime = [True] * (max_val + 1)
        is_prime[0] = is_prime[1] = False
        for p in range(2, int(max_val**0.5) + 1):
            if is_prime[p]:
                for i in range(p * p, max_val + 1, p):
                    is_prime[i] = False
                    
        # Step 2: Map each value to a list of its indices
        val_to_idx = [[] for _ in range(max_val + 1)]
        for i, v in enumerate(nums):
            val_to_idx[v].append(i)
            
        # Step 3: BFS Initialization
        visited_idx = [False] * n
        visited_prime = [False] * (max_val + 1)
        
        queue = deque([0])
        visited_idx[0] = True
        jumps = 0
        
        while queue:
            for _ in range(len(queue)):
                u = queue.popleft()
                
                # Option 1: Adjacent steps
                for v in (u - 1, u + 1):
                    if 0 <= v < n and not visited_idx[v]:
                        if v == n - 1:
                            return jumps + 1
                        visited_idx[v] = True
                        queue.append(v)
                        
                # Option 2: Prime Teleportation
                p = nums[u]
                if is_prime[p] and not visited_prime[p]:
                    visited_prime[p] = True
                    
                    # Jump to all indices holding a multiple of the prime p
                    for multiple in range(p, max_val + 1, p):
                        if val_to_idx[multiple]:
                            for v in val_to_idx[multiple]:
                                if not visited_idx[v]:
                                    if v == n - 1:
                                        return jumps + 1
                                    visited_idx[v] = True
                                    queue.append(v)
                            
                            # Optimization: Clear the bucket. 
                            # These indices have been reached optimally; no other prime needs to visit them.
                            val_to_idx[multiple].clear()
                                
            jumps += 1
            
        return -1
