# Intuition
The problem asks us to find the string in `wordsContainer` that shares the longest common suffix with each query in `wordsQuery`. When searching for prefixes, a **Trie (Prefix Tree)** is the standard data structure. Since we are looking for *suffixes*, we can simply reverse all the strings and use a standard Trie!

To handle the tie-breaking rules efficiently:
1. Longest common suffix
2. Shortest string length
3. Earliest index

We can store the "best" index directly inside each Trie node. As we insert the reversed strings from `wordsContainer` into the Trie, we update the best index at each node we visit. This way, when we traverse the Trie for a query, the node where we stop will already contain the exact index we need to return.

# Approach
1. **Find Global Best:** First, find the index of the shortest word in `wordsContainer`. If there are ties, the earliest index wins. This global best index is the default answer for any query that has absolutely no common suffix (the empty string `""` match).
2. **Build the Trie:** * Initialize the root of the Trie with this global best index.
   * For each word in `wordsContainer`, iterate through its characters in **reverse** order.
   * As you traverse/create nodes, check the current best index stored at that node. If the current word is shorter than the word associated with the node's best index, update the node's best index. (Because we process words in order from index `0` to `n-1`, the "earliest index" tie-breaker is naturally handled by only updating when the length is strictly less).
3. **Query the Trie:**
   * For each query in `wordsQuery`, traverse its characters in **reverse** order through the Trie.
   * Stop when you reach the end of the query or encounter a character that isn't in the current node's children.
   * The answer for this query is simply the `best_index` stored at the last node you successfully reached.

# Complexity
- **Time complexity:** $O(C + Q)$
  Where $C$ is the sum of the lengths of all strings in `wordsContainer` and $Q$ is the sum of the lengths of all strings in `wordsQuery`. Building the Trie takes time proportional to the total number of characters in the container, and querying takes time proportional to the total characters in the queries.
- **Space complexity:** $O(C)$
  In the worst-case scenario (where no words share any suffixes), we will create a new Trie node for every single character in `wordsContainer`.

# Code
```python3 []
class TrieNode:
    def __init__(self, best_idx: int):
        self.children = {}
        # Stores the index of the best word that passes through this node
        self.best_idx = best_idx

class Solution:
    def stringIndices(self, wordsContainer: list[str], wordsQuery: list[str]) -> list[int]:
        # Step 1: Find the global best index for queries with 0 matching suffix characters
        global_best_idx = 0
        for i in range(1, len(wordsContainer)):
            if len(wordsContainer[i]) < len(wordsContainer[global_best_idx]):
                global_best_idx = i
                
        root = TrieNode(global_best_idx)
        
        # Step 2: Build the Trie with reversed words
        for i, word in enumerate(wordsContainer):
            curr = root
            for char in reversed(word):
                if char not in curr.children:
                    curr.children[char] = TrieNode(i)
                else:
                    # Update the best index for this node if the current word is shorter
                    curr_best_idx = curr.children[char].best_idx
                    if len(word) < len(wordsContainer[curr_best_idx]):
                        curr.children[char].best_idx = i
                    # Note: We do nothing if lengths are equal, because the existing
                    # curr_best_idx is guaranteed to be a smaller index (we iterate i upwards).
                
                curr = curr.children[char]
                
        # Step 3: Process the queries
        ans = []
        for query in wordsQuery:
            curr = root
            for char in reversed(query):
                if char in curr.children:
                    curr = curr.children[char]
                else:
                    # Break as soon as the suffix stops matching
                    break
            
            # The last successfully reached node holds the pre-calculated best answer
            ans.append(curr.best_idx)
            
        return ans
