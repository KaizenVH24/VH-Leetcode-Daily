# Intuition
To determine if a number is "good", we need to look at its individual digits. We can categorize the digits from 0 to 9 into three distinct groups based on how they behave when rotated 180 degrees:
1.  **Invalid Digits:** `3`, `4`, and `7`. If a number contains *any* of these digits, the entire number becomes invalid upon rotation.
2.  **Rotating Digits:** `2`, `5`, `6`, and `9`. These digits transform into different valid digits. 
3.  **Neutral Digits:** `0`, `1`, and `8`. These digits remain exactly the same after rotation.

For a number to be considered "good" (meaning it forms a valid, *different* number after rotation), it must strictly satisfy two conditions:
1.  It contains **zero** invalid digits.
2.  It contains **at least one** rotating digit. (If it only contained neutral digits, it would rotate into the exact same number, which violates the requirement that the new number must be different).

# Approach
Given the relatively small constraint ($n \le 10^4$), an elegant and fast approach is to simply iterate through all numbers from 1 to $n$. 
1. Convert each number to a string to easily inspect its digits.
2. If the string contains `'3'`, `'4'`, or `'7'`, immediately skip it.
3. If it passes the first check and contains `'2'`, `'5'`, `'6'`, or `'9'`, increment our `good_count`.
4. Return the final count.

*Note: In Python, directly checking substrings (`'3' in s`) is implemented in C and is highly optimized, often running faster than converting the string to a set of characters for intersection.*

# Complexity
- Time complexity:
$$O(N \log_{10} N)$$
Where $N$ is the given integer `n`. We iterate $N$ times. In each iteration, converting the number to a string and scanning its characters takes time proportional to the number of digits, which is $\log_{10} N$. Since $N \le 10000$, $\log_{10} N \le 5$, making this extremely fast (effectively $O(N)$ in practice).

- Space complexity:
$$O(\log_{10} N)$$
We convert each integer to a string, which takes space proportional to the number of digits in the integer.

class Solution:
    def rotatedDigits(self, n: int) -> int:
        good_count = 0
        
        for i in range(1, n + 1):
            s = str(i)
            
            # Condition 1: Must not contain any invalid digits
            if '3' in s or '4' in s or '7' in s:
                continue
                
            # Condition 2: Must contain at least one rotating digit
            if '2' in s or '5' in s or '6' in s or '9' in s:
                good_count += 1
                
        return good_count
