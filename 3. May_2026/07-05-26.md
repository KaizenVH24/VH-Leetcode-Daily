# Intuition
The key to unlocking this problem is realizing that the jump rules define an **undirected graph**. 
Let's analyze the conditions carefully:
1.  **Forward Jump**: From $i$ to $j$ ($i < j$), you need `nums[i] > nums[j]`.
2.  **Backward Jump**: From $j$ to $i$ ($i < j$), you need `nums[j] < nums[i]`.

Notice that both rules dictate the exact same condition: you can jump between two indices if and only if the earlier index has a strictly greater value. Because both the forward and backward rules map to the same pairs of indices, every jump is fully reversible.

This means we are looking at an undirected graph known as an **inversion graph**. In an undirected graph, if you can reach a node, you can reach all nodes in its connected component. Thus, the maximum value reachable from any starting index is simply the **maximum value in its connected component**.

A well-known mathematical property of inversion graphs is that their connected components always form **contiguous subsegments** of the array. You can draw a boundary to split the array into disconnected components at index `i` if and only if the maximum element on the left side is less than or equal to the minimum element on the right side. If $\max(\text{left}) \le \min(\text{right})$, no element on the left can form an inversion with any element on the right, meaning no edges cross the boundary.

# Approach
1.  **Prefix Max Array**: Create an array `prefix_max` where `prefix_max[i]` stores the maximum value from index `0` up to `i`.
2.  **Suffix Min Array**: Create an array `suffix_min` where `suffix_min[i]` stores the minimum value from index `i` down to the end of the array.
3.  **Find Components**: Iterate through the array. We can safely "split" and end a connected component at index `i` if `prefix_max[i] <= suffix_min[i + 1]`.
4.  **Assign Maximums**: Keep track of the `start` index of the current component. When we find a split at `i`, the subarray `nums[start...i]` forms a complete connected component. 
    * *Elegant optimization*: Because of the split condition, the maximum value in this component is guaranteed to simply be `prefix_max[i]`. We just assign `prefix_max[i]` to our answer array for all indices from `start` to `i`.
5.  Update `start` to `i + 1` and continue until the end of the array.

# Complexity
- Time complexity:
$$O(N)$$
We iterate through the `nums` array a few times: once to build `prefix_max`, once to build `suffix_min`, and once to find the boundaries and populate the answer array. All passes are strictly linear.

- Space complexity:
$$O(N)$$
We use auxiliary space to store the `prefix_max`, `suffix_min`, and the `ans` output arrays, which all scale linearly with the length of the input.

```python3 []
class Solution:
    def maximumScore(self, nums: list[int]) -> list[int]:
        n = len(nums)
        if n == 0:
            return []
            
        # Step 1: Precompute prefix maximums
        prefix_max = [0] * n
        prefix_max[0] = nums[0]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], nums[i])
            
        # Step 2: Precompute suffix minimums
        suffix_min = [0] * n
        suffix_min[-1] = nums[-1]
        for i in range(n - 2, -1, -1):
            suffix_min[i] = min(suffix_min[i + 1], nums[i])
            
        ans = [0] * n
        start = 0
        
        # Step 3: Find boundaries and populate answers
        for i in range(n):
            # A component ends here if there are no elements to the right
            # that are strictly smaller than any element to the left
            if i == n - 1 or prefix_max[i] <= suffix_min[i + 1]:
                
                # The maximum of the current isolated component is simply prefix_max[i]
                comp_max = prefix_max[i]
                
                # Assign the component's maximum to all its members
                for j in range(start, i + 1):
                    ans[j] = comp_max
                    
                # Move the start pointer for the next component
                start = i + 1
                
        return ans
