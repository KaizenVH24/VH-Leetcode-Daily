# Intuition
Rotating a 2D matrix by 90 degrees clockwise in a single pass can involve messy index calculations. However, there's a highly elegant linear algebra trick to achieve this easily in two simple steps. If you **transpose** the matrix (swap rows and columns) and then **reverse** each row, you get a perfectly rotated 90-degree clockwise matrix.

Let's look at a 3x3 example:
**1. Original Matrix:**
[1, 2, 3]
[4, 5, 6]
[7, 8, 9]

**2. Transpose (swap `matrix[i][j]` with `matrix[j][i]`):**
[1, 4, 7]
[2, 5, 8]
[3, 6, 9]

**3. Reverse every row:**
[7, 4, 1]
[8, 5, 2]
[9, 6, 3]  <-- This is your 90-degree rotated matrix!

# Approach
1. **Transpose the matrix:** Iterate through the top-right triangle of the matrix (where `i < j`). For each element, swap `matrix[i][j]` with `matrix[j][i]`. 
2. **Reverse each row:** Iterate through every row in the matrix and reverse its elements. Since we need to do this in-place, we can use a two-pointer approach (left and right) for each row, or utilize built-in language features that mutate the array in-place.

# Complexity
- **Time complexity:** $O(n^2)$
  We iterate through half the matrix for the transpose operation, and then through the entire matrix to reverse the rows. Since the matrix has $n \times n$ elements, the time scales quadratically with the dimension `n`.
- **Space complexity:** $O(1)$
  We do not allocate any additional 2D matrices. All swaps and reversals are done strictly in-place, requiring only a constant amount of extra memory for temporary variables during the swaps.

# Code
```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)
        
        # Step 1: Transpose the matrix
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
                
        # Step 2: Reverse each row
        for i in range(n):
            # In Python, we can reverse a list in-place using .reverse()
            matrix[i].reverse()

            # left, right = 0, n - 1

            #     left += 1
            #     right -= 1
