# Intuition
The problem asks for the maximum number of indices we can visit starting from *any* index, given a specific set of jumping rules. The core constraint is that we can only jump from a taller bar to a strictly shorter bar, and we cannot jump over any bar that is taller than or equal to our starting bar.

Because we are always jumping from a larger value to a smaller value, it is physically impossible to form a cycle (you can never jump back to a bar you've already visited, as that would require jumping up). This means our jump paths form a **Directed Acyclic Graph (DAG)**. 

Whenever we need to find the longest path in a DAG, **Depth-First Search (DFS) with Memoization** (or Top-Down Dynamic Programming) is the perfect approach. We can define a state `dp[i]` as the maximum number of jumps we can make starting from index `i`.

# Approach
1.  **Initialize Memoization:** Create an array `dp` of size `n` initialized to `0`. `dp[i]` will store the maximum number of indices we can visit starting from index `i`.
2.  **Define DFS Function:** Create a recursive function `dfs(i)`:
    * If `dp[i]` is already computed (i.e., not `0`), return it immediately.
    * Every index can visit at least itself, so initialize `max_jumps = 1`.
    * **Explore Right:** Loop `j` from `i + 1` up to `i + d`.
        * Ensure `j` is within array bounds.
        * If `arr[j] >= arr[i]`, we cannot jump to it, nor can we jump *over* it. Break the loop early.
        * Otherwise, update `max_jumps = max(max_jumps, 1 + dfs(j))`.
    * **Explore Left:** Loop `j` from `i - 1` down to `i - d`.
        * Ensure `j` is within array bounds.
        * If `arr[j] >= arr[i]`, break the loop early for the same blocking reason.
        * Otherwise, update `max_jumps = max(max_jumps, 1 + dfs(j))`.
    * Save `max_jumps` into `dp[i]` and return it.
3.  **Compute Maximum:** Iterate through every possible starting index `i` from `0` to `n - 1`, call `dfs(i)`, and keep track of the global maximum.
4.  **Return:** Return the global maximum.

# Complexity
- **Time complexity:** $O(n \cdot d)$
  Where $n$ is the length of the array and $d$ is the maximum jump distance. Because of memoization, we compute the result for each index exactly once. For each index, we look at up to $d$ elements to the right and $d$ elements to the left.
- **Space complexity:** $O(n)$
  We use an array `dp` of size $n$ to store the memoized results. The recursion stack for DFS will also go at most $n$ levels deep in the worst case (e.g., a strictly decreasing array where $d=1$).

```python3 []
class Solution:
    def maxJumps(self, arr: list[int], d: int) -> int:
        n = len(arr)
        dp = [0] * n
        
        def dfs(i: int) -> int:
            if dp[i] != 0:
                return dp[i]
                
            max_jumps = 1
            
            # Jump Right
            for j in range(i + 1, min(i + d + 1, n)):
                if arr[j] >= arr[i]:
                    break  # Blocked by a taller or equal bar
                max_jumps = max(max_jumps, 1 + dfs(j))
                
            # Jump Left
            for j in range(i - 1, max(i - d - 1, -1), -1):
                if arr[j] >= arr[i]:
                    break  # Blocked by a taller or equal bar
                max_jumps = max(max_jumps, 1 + dfs(j))
                
            dp[i] = max_jumps
            return max_jumps
            
        # Calculate max jumps from all possible starting positions
        ans = 0
        for i in range(n):
            ans = max(ans, dfs(i))
            
        return ans
