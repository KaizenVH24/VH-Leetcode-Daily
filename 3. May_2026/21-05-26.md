# Intuition
A brute-force solution checking every pair between `arr1` and `arr2` would take $\mathcal{O}(N \times M)$ time. Given the constraints ($50,000$ elements per array), this results in roughly $2.5 \times 10^9$ operations, which will instantly trigger a Time Limit Exceeded (TLE) error.

However, the maximum value for any integer in the arrays is $10^8$. This is a massive hint: an integer up to $10^8$ has at most 9 digits. This means each number only has at most 9 possible prefixes. Instead of comparing pairs, we can generate every single prefix for all numbers in `arr1` and dump them into a Hash Set. Then, we can take each number in `arr2`, generate its prefixes (starting from the longest), and check if it exists in the set.

# Approach
1.  **Build a Prefix Set:** Initialize an empty Hash Set. Iterate through each number in `arr1`.
2.  **Generate Prefixes via Math:** Instead of converting numbers to strings and slicing them (which is slow), we can generate prefixes mathematically by repeatedly performing integer division by 10 (`num //= 10`). Add each resulting prefix to the set.
3.  **Find the Longest Match:** Iterate through each number in `arr2`. Repeatedly divide it by 10 to check its prefixes against the set.
4.  **Early Exit:** Because we start with the full number and divide down, the *very first* match we find in the set for a specific number in `arr2` is guaranteed to be its longest common prefix. We update our `max_len` using `len(str(num))` and instantly `break` to the next number.

# Complexity
- Time complexity:
$$O(N \cdot d + M \cdot d)$$
Where $N$ and $M$ are the lengths of `arr1` and `arr2`, and $d$ is the maximum number of digits (which is strictly bounded at 9). The set lookups take $O(1)$ time. Because $d$ is a small constant, this effectively simplifies to a linear time complexity of $O(N + M)$.

- Space complexity:
$$O(N \cdot d)$$
We store up to 9 prefixes for every number in `arr1` inside our Hash Set.

class Solution:
    def longestCommonPrefix(self, arr1: list[int], arr2: list[int]) -> int:
        prefixes = set()
        
        # Store all possible prefixes for every number in arr1
        for num in arr1:
            while num > 0:
                prefixes.add(num)
                num //= 10
                
        max_len = 0
        
        # Check prefixes for numbers in arr2 against the set
        for num in arr2:
            while num > 0:
                if num in prefixes:
                    # The first match is inherently the longest for this number
                    max_len = max(max_len, len(str(num)))
                    break
                num //= 10
                
        return max_len
