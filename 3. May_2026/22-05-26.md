# Intuition
The strict $O(\log n)$ time complexity requirement is a massive hint that we need to use **Binary Search**. 

Normally, binary search requires a fully sorted array. However, a rotated sorted array has a very special property: if you pick any midpoint to split the array into two halves, **at least one of those halves will always be perfectly sorted**. 

By determining which half is correctly sorted, we can easily check if our `target` lies within that half's boundaries. If it does, we narrow our search to that half. If it doesn't, the target *must* be in the other, unsorted (or rotated) half.

# Approach
1.  **Initialize Pointers:** Set `left = 0` and `right = len(nums) - 1`.
2.  **Binary Search Loop:** Run a `while left <= right` loop.
3.  **Find Midpoint:** Calculate `mid = left + (right - left) // 2`. Check if `nums[mid] == target`. If so, return `mid`.
4.  **Determine the Sorted Half:**
    * **Left Half is Sorted** (`nums[left] <= nums[mid]`):
        * Check if the `target` falls within this perfectly sorted range: `nums[left] <= target < nums[mid]`.
        * If it does, the target must be in the left half, so move the right pointer: `right = mid - 1`.
        * If it doesn't, the target must be in the right half, so move the left pointer: `left = mid + 1`.
    * **Right Half is Sorted** (`nums[mid] <= nums[right]`):
        * Check if the `target` falls within this perfectly sorted range: `nums[mid] < target <= nums[right]`.
        * If it does, the target must be in the right half, so move the left pointer: `left = mid + 1`.
        * If it doesn't, the target must be in the left half, so move the right pointer: `right = mid - 1`.
5.  **Not Found:** If the loop terminates without finding the target, return `-1`.

# Complexity
- **Time complexity:** $\mathcal{O}(\log n)$
  In every step of the loop, we eliminate exactly half of the remaining search space, resulting in a logarithmic time complexity.
- **Space complexity:** $\mathcal{O}(1)$
  We only use a few integer variables (`left`, `right`, `mid`) to track indices, which takes constant extra memory.

class Solution:
    def search(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            
            # Target found
            if nums[mid] == target:
                return mid
                
            # Check if the left half is strictly sorted
            if nums[left] <= nums[mid]:
                # Is the target within this sorted left half?
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
                    
            # Otherwise, the right half must be strictly sorted
            else:
                # Is the target within this sorted right half?
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
                    
        return -1
