# Intuition
Since both arrays are already sorted in ascending order, we can use a **Two-Pointer** approach to find the minimum common value efficiently. By placing one pointer at the start of each array, we can compare the current elements. If they match, we've found our minimum common value. If one is smaller than the other, we simply advance the pointer of the smaller element to try and "catch up" to the larger one. 

# Approach
1. Initialize two pointers, `i = 0` for `nums1` and `j = 0` for `nums2`.
2. Iterate using a `while` loop as long as both `i` and `j` are within the bounds of their respective arrays.
3. In each iteration, compare `nums1[i]` and `nums2[j]`:
   * If `nums1[i] == nums2[j]`, we have found the smallest common element. Return it immediately.
   * If `nums1[i] < nums2[j]`, the element in `nums1` is too small. Increment `i` to look at the next, larger element in `nums1`.
   * If `nums1[i] > nums2[j]`, the element in `nums2` is too small. Increment `j` to look at the next, larger element in `nums2`.
4. If the loop terminates without finding a match, it means there are no common elements. Return `-1`.

# Complexity
- **Time complexity:** $\mathcal{O}(N + M)$
  Where $N$ is the length of `nums1` and $M$ is the length of `nums2`. In the worst-case scenario, we traverse both arrays completely (e.g., when there is no common element and we reach the end of both).
- **Space complexity:** $\mathcal{O}(1)$
  We only use two integer pointers (`i` and `j`), requiring constant extra memory regardless of the input array sizes.

class Solution:
    def getCommon(self, nums1: list[int], nums2: list[int]) -> int:
        i, j = 0, 0
        
        while i < len(nums1) and j < len(nums2):
            if nums1[i] == nums2[j]:
                return nums1[i]
            elif nums1[i] < nums2[j]:
                i += 1
            else:
                j += 1
                
        return -1
