# Intuition
This problem builds upon the previous "Special Characters" problem by adding a strict ordering constraint. Not only must both the lowercase and uppercase versions of a letter exist, but **all** lowercase occurrences must appear strictly *before* the **first** uppercase occurrence.

This means we only need to track two specific pieces of information for every letter in the alphabet:
1. The **last** index where its lowercase version appeared.
2. The **first** index where its uppercase version appeared.

If a letter exists in both forms, and its `last_lower_index < first_upper_index`, it perfectly satisfies the condition. 

# Approach
1.  **Initialize Trackers:** Create two arrays of size 26 (to represent the English alphabet), `last_lower` and `first_upper`. Initialize all values to `-1` to represent that a character hasn't been seen yet.
2.  **First Pass (Scan the String):** Iterate through the string `word` alongside its indices:
    * If the character is lowercase, aggressively overwrite its position in `last_lower`. This naturally guarantees that by the end of the loop, we hold its *last* seen index.
    * If the character is uppercase, check if its position in `first_upper` is still `-1`. If it is, record the current index. This guarantees we only store its *first* seen index.
3.  **Second Pass (Check the Alphabet):** Iterate through the numbers $0$ to $25$ (representing 'a' to 'z'):
    * Check if both the lowercase and uppercase versions were found (i.e., their indices are not `-1`).
    * Check if `last_lower[i] < first_upper[i]`.
    * If both conditions are met, increment our `count`.
4.  **Return:** Return the final `count`.

# Complexity
- **Time complexity:** $\mathcal{O}(N)$
  Where $N$ is the length of the string `word`. We scan the string exactly once. The second loop always runs exactly 26 times, which is a constant $\mathcal{O}(1)$ operation. Thus, the time complexity scales perfectly linearly.
- **Space complexity:** $\mathcal{O}(1)$
  We allocate two arrays of size 26. Since the size of these arrays is strictly bounded by the alphabet and does not grow with the input size $N$, the space complexity is constant.

```python3 []
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        # Arrays to store indices, initialized to -1
        last_lower = [-1] * 26
        first_upper = [-1] * 26
        
        # Scan the word to populate the last and first indices
        for i, char in enumerate(word):
            if char.islower():
                # Map 'a'-'z' to 0-25
                idx = ord(char) - ord('a')
                last_lower[idx] = i
            else:
                # Map 'A'-'Z' to 0-25
                idx = ord(char) - ord('A')
                # Only record the very first occurrence
                if first_upper[idx] == -1:
                    first_upper[idx] = i
                    
        count = 0
        
        # Validate all 26 letters against the ordering condition
        for i in range(26):
            if last_lower[i] != -1 and first_upper[i] != -1:
                if last_lower[i] < first_upper[i]:
                    count += 1
                    
        return count
