# Intuition
The problem asks us to dynamically place obstacles on a number line and query whether a block of size `sz` can fit in the range `[0, x]` without overlapping any obstacles. 

If we have a set of obstacles in the range `[0, x]`, the available spaces to place a block are essentially the gaps between adjacent obstacles. The largest block we can fit will be bounded by the **maximum gap** between any two adjacent obstacles $\le x$. Additionally, we must also consider the gap between the *last* obstacle $\le x$ and the boundary $x$ itself.

Because we are dealing with dynamic point updates (adding obstacles) and range queries (finding the max gap in `[0, x]`), a **Segment Tree** is the perfect data structure.

# Approach
1. **Segment Tree Design:** We will build a segment tree over the coordinate domain from $0$ up to the maximum $x$ value given in the queries.
2. **Node Properties:** Each node in the segment tree representing a range $[L, R]$ will maintain three values:
    * `min_val`: The coordinate of the first (smallest) obstacle in this range.
    * `max_val`: The coordinate of the last (largest) obstacle in this range.
    * `max_gap`: The maximum gap between any two adjacent obstacles strictly within this range.
3. **Merging Nodes:** When combining a left child and a right child:
    * The new `min_val` is the minimum of their `min_val`s.
    * The new `max_val` is the maximum of their `max_val`s.
    * The new `max_gap` is the maximum of:
        * The left child's `max_gap`
        * The right child's `max_gap`
        * The gap spanning across the middle: `right_child.min_val - left_child.max_val`.
4. **Processing Queries:**
    * **Add Obstacle (`[1, x]`):** Update the segment tree at index `x`. Its `min_val` and `max_val` become `x`, and its `max_gap` is $0$.
    * **Check Block (`[2, x, sz]`):** Query the segment tree for the range `[0, x]`. This returns the `max_gap` between obstacles up to $x$, and the `max_val` (the last obstacle $\le x$). The total available space is the maximum of the internal `max_gap` and the boundary gap $x - \text{max\_val}$. Return `True` if this available space is $\ge sz$, otherwise `False`.
5. **Initial State:** The problem requires the block to fit in `[0, x]`, implying that $0$ acts as a starting boundary. We manually insert an obstacle at $0$ before processing any queries.

# Complexity
- **Time Complexity:** - **Building/Updates/Queries:** Each segment tree update and query takes $O(\log M)$ time, where $M$ is the maximum coordinate ($X \le 50,000$). 
  - **Total Time:** $O(Q \log M)$, where $Q$ is the number of queries. Given $Q \le 1.5 \times 10^5$, this will run well within the time limits.
- **Space Complexity:** $O(M)$ where $M$ is the maximum coordinate we track. We use three arrays of size $4 \times M$ for the segment tree, taking $O(M)$ auxiliary space.

class Solution:
    def getResults(self, queries: list[list[int]]) -> list[bool]:
        INF = float('inf')
        
        # Find the max coordinate we will ever query or update to optimize the segment tree size
        MAX_X = max(q[1] for q in queries) + 1
        
        # Segment tree arrays
        tree_min = [INF] * (4 * MAX_X)
        tree_max = [-INF] * (4 * MAX_X)
        tree_gap = [0] * (4 * MAX_X)
        
        def update(node: int, l: int, r: int, idx: int):
            if l == r:
                tree_min[node] = idx
                tree_max[node] = idx
                tree_gap[node] = 0
                return
            
            mid = (l + r) // 2
            if idx <= mid:
                update(2 * node, l, mid, idx)
            else:
                update(2 * node + 1, mid + 1, r, idx)
                
            # Merge children
            tree_min[node] = min(tree_min[2 * node], tree_min[2 * node + 1])
            tree_max[node] = max(tree_max[2 * node], tree_max[2 * node + 1])
            tree_gap[node] = max(tree_gap[2 * node], tree_gap[2 * node + 1])
            
            # Check the gap spanning across the left and right children
            if tree_max[2 * node] != -INF and tree_min[2 * node + 1] != INF:
                spanning_gap = tree_min[2 * node + 1] - tree_max[2 * node]
                tree_gap[node] = max(tree_gap[node], spanning_gap)
                
        def query(node: int, l: int, r: int, ql: int, qr: int):
            # Completely within range
            if ql <= l and r <= qr:
                return (tree_min[node], tree_max[node], tree_gap[node])
            
            mid = (l + r) // 2
            
            # Only overlaps with left child
            if qr <= mid:
                return query(2 * node, l, mid, ql, qr)
            # Only overlaps with right child
            elif ql > mid:
                return query(2 * node + 1, mid + 1, r, ql, qr)
            # Overlaps with both
            else:
                left_min, left_max, left_gap = query(2 * node, l, mid, ql, qr)
                right_min, right_max, right_gap = query(2 * node + 1, mid + 1, r, ql, qr)
                
                res_min = min(left_min, right_min)
                res_max = max(left_max, right_max)
                res_gap = max(left_gap, right_gap)
                
                if left_max != -INF and right_min != INF:
                    res_gap = max(res_gap, right_min - left_max)
                    
                return (res_min, res_max, res_gap)

        # The origin acts as an implicit boundary obstacle
        update(1, 0, MAX_X, 0)
        
        results = []
        for q in queries:
            if q[0] == 1:
                update(1, 0, MAX_X, q[1])
            else:
                x, sz = q[1], q[2]
                
                # Query the segment tree for the range [0, x]
                _, max_val, max_gap = query(1, 0, MAX_X, 0, x)
                
                # The total space available is either a gap between two obstacles <= x
                # OR the gap between the last obstacle <= x and x itself.
                best_space = max(max_gap, x - max_val)
                
                results.append(best_space >= sz)
                
        return results
