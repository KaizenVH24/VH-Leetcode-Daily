# Intuition
The problem asks us to find how many letters exist in both their lowercase and uppercase forms within a given string. Since we only care about *presence* and not *frequency* (it doesn't matter if 'a' appears once or ten times, as long as it's there alongside an 'A'), we can use a Hash Set. 

Sets give us the ability to look up whether a character exists in the string in constant $O(1)$ time. Once we have all the unique characters from the string in a set, we simply iterate through the 26 lowercase English letters and check if both the lowercase and uppercase versions are present in our set.

# Approach
1.  **Build a Set:** Convert the input string `word` into a set of characters called `char_set`. This automatically removes duplicates and allows for instant lookups.
2.  **Initialize Counter:** Create a `count` variable set to `0` to keep track of our special characters.
3.  **Check the Alphabet:** Loop through all 26 lowercase English letters (e.g., from 'a' to 'z').
4.  **Validate Special Condition:** For each letter, check if *both* the lowercase version (`char`) and the uppercase version (`char.upper()`) exist in `char_set`.
5.  **Count and Return:** If both exist, increment `count`. After checking all 26 letters, return the final `count`.

# Complexity
- **Time complexity:** $\mathcal{O}(N)$
  Where $N$ is the length of the string `word`. Converting the string to a set requires one linear pass, taking $\mathcal{O}(N)$ time. Checking the alphabet takes exactly 26 constant-time lookups, which is strictly $\mathcal{O}(1)$. Thus, the overall time scales linearly with the input string.
  
- **Space complexity:** $\mathcal{O}(1)$
  The set `char_set` will store at most 52 unique characters (26 lowercase + 26 uppercase). Since this maximum size is bounded by a constant and does not grow infinitely with $N$, the space complexity is $\mathcal{O}(1)$.

class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        # Create a hash set for O(1) lookups
        char_set = set(word)
        count = 0
        
        # Check all 26 lowercase letters
        for char in "abcdefghijklmnopqrstuvwxyz":
            # A letter is special if both its lower and upper forms are in the set
            if char in char_set and char.upper() in char_set:
                count += 1
                
        return count
