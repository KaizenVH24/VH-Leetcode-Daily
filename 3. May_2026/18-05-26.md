# Intuition
The problem asks for the *minimum* number of steps to reach the end of an array. Finding the shortest path in an unweighted graph is a classic use case for Breadth-First Search (BFS). 

In this graph, every index `i` is a node. The edges connecting the nodes are defined by the jump rules:
1. An edge to `i - 1`
2. An edge to `i + 1`
3. Edges to all indices `j` where `arr[i] == arr[j]`

The naive BFS approach would be to check all these edges for every node we visit. However, if an array has many identical values (e.g., an array of 50,000 zeros), checking the `arr[i] == arr[j]` condition repeatedly will result in an $O(N^2)$ Time Limit Exceeded (TLE) error. 

The crucial optimization is realizing that all nodes with the same value are essentially connected in a fully connected subgraph. Once you jump to *any* node of a specific value and add all its identical-value siblings to the BFS queue, you have already found the shortest path to all of them. Therefore, you should immediately **delete or clear** that value from your lookup map so you never waste time iterating over those same sibling nodes again.

# Approach
1. **Handle Base Case:** If the array has length 1, we are already at the last index, so return `0`.
2. **Build the Graph Map:** Create a hash map (dictionary) where the keys are the values in the array, and the values are lists of indices where that value occurs.
3. **Initialize BFS:** - Use a `queue` starting with index `0`.
   - Use a `visited` set to avoid cycles, starting with `{0}`.
   - Keep a `steps` counter starting at `0`.
4. **Process Level by Level:**
   - Loop through the current elements in the queue. Pop an index `curr`.
   - If `curr` is the last index (`n - 1`), return the current `steps`.
   - **Identical Value Jumps:** Look up `arr[curr]` in the hash map. For every unvisited index in that list, mark it as visited and add it to the queue. 
   - **Crucial Step:** Clear the list in the hash map for `arr[curr]` (`graph[arr[curr]].clear()`). This guarantees $O(1)$ amortized time for identical value lookups moving forward.
   - **Adjacent Jumps:** Check `curr - 1` and `curr + 1`. If they are within bounds and unvisited, add them to the queue and mark them as visited.
5. **Increment Steps:** After processing the entire level of the queue, increment `steps` by 1.

# Complexity
- **Time complexity:** $\mathcal{O}(N)$
  Where $N$ is the length of `arr`. Building the hash map takes $\mathcal{O}(N)$. Because we clear the value lists in the hash map after their first use, the inner loop iterating over identical values runs at most $N$ times globally across the entire BFS. Every index is added to the queue at most once, making the overall traversal strictly linear.
- **Space complexity:** $\mathcal{O}(N)$
  The hash map stores $N$ indices. The BFS queue and the `visited` set can also hold up to $N$ elements in the worst case.

from collections import defaultdict, deque

class Solution:
    def minJumps(self, arr: list[int]) -> int:
        n = len(arr)
        if n <= 1:
            return 0
            
        # Map each value to a list of all its indices
        graph = defaultdict(list)
        for i, val in enumerate(arr):
            graph[val].append(i)
            
        queue = deque([0])
        visited = {0}
        steps = 0
        
        while queue:
            # Process the current BFS level
            for _ in range(len(queue)):
                curr = queue.popleft()
                
                # If we reached the target
                if curr == n - 1:
                    return steps
                    
                # 1. Explore jumps to identical values
                for neighbor in graph[arr[curr]]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
                        
                # Optimization: clear the list so we don't process these edges again
                graph[arr[curr]].clear()
                
                # 2. Explore adjacent jumps (left and right)
                for neighbor in (curr - 1, curr + 1):
                    if 0 <= neighbor < n and neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
                        
            steps += 1
            
        return -1
