# Intuition
A perfectly sorted array in non-decreasing order has zero "drops" (points where a number is strictly greater than the number immediately following it). 

When you take a sorted array and rotate it, you shift elements from the end to the beginning. This introduces exactly **one** drop at the point of rotation (where the original end of the array meets the original beginning). 

Therefore, for an array to be a valid rotated sorted array, it must have **at most one drop**. If it has zero drops, it's fully sorted (rotated 0 times). If it has more than one drop, it is structurally invalid and cannot be formed by a simple rotation. We also need to check the wrap-around boundary (comparing the last element to the first element) as part of this count.

# Approach
1.  **Initialize a Counter:** Set `drop_count = 0` to track the number of times the sequence decreases.
2.  **Iterate and Compare:** Loop through the array. For every index `i`, compare `nums[i]` with the next element `nums[(i + 1) % n]`. 
    * *Note:* Using modulo `% n` elegantly handles the wrap-around comparison between the very last element and the very first element without needing extra logic.
3.  **Count Drops:** If `nums[i] > nums[(i + 1) % n]`, increment `drop_count`.
4.  **Validate:** At any point, if `drop_count > 1`, we can immediately return `False`.
5.  **Return:** If the loop completes and `drop_count` is 0 or 1, return `True`.

# Complexity
- **Time complexity:** $\mathcal{O}(N)$
  Where $N$ is the length of the array. We iterate through the array exactly once, performing constant-time comparisons.
- **Space complexity:** $\mathcal{O}(1)$
  We only use a single integer variable (`drop_count`), requiring constant extra space.

# Code
```python3 []
class Solution:
    def check(self, nums: list[int]) -> bool:
        drop_count = 0
        n = len(nums)
        
        for i in range(n):
            # Compare current element to the next element (with wrap-around)
            if nums[i] > nums[(i + 1) % n]:
                drop_count += 1
                
            # If there's more than one drop, it can't be a rotated sorted array
            if drop_count > 1:
                return False
                
        return True
