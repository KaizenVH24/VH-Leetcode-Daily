# Intuition
To maximize the planet's chances of destroying all asteroids, it should always pick the easiest targets first. By consuming the smallest asteroids available, the planet safely and incrementally builds up its mass. This increased mass then allows it to take on larger asteroids that it initially couldn't destroy. This naturally suggests a **Greedy** approach.

# Approach
1.  **Sort the Asteroids:** Sort the `asteroids` array in ascending order. This guarantees that we always face the smallest remaining asteroid next.
2.  **Iterate and Accumulate:** Loop through the sorted array. 
    * If the planet's current `mass` is greater than or equal to the current asteroid's mass, we destroy it and add its mass to the planet.
    * If the planet's `mass` is strictly less than the current asteroid, it means we cannot destroy it. Since the array is sorted, we also won't be able to destroy any of the subsequent asteroids. We can immediately return `False`.
3.  **Return True:** If we successfully loop through the entire array without failing, it means all asteroids were destroyed, so we return `True`.

# Complexity
- **Time complexity:**
$$O(N \log N)$$
Where $N$ is the number of asteroids. The most computationally expensive step is sorting the array, which takes $O(N \log N)$ time. The subsequent linear scan takes $O(N)$ time.

- **Space complexity:**
$$O(1) \text{ or } O(N)$$
If we sort the array in place, the conceptual auxiliary space is $O(1)$. However, it's worth noting that Python's built-in `sort()` (Timsort) requires $O(N)$ space in the worst case.

class Solution:
    def asteroidsDestroyed(self, mass: int, asteroids: list[int]) -> bool:
        # Sort to encounter the smallest asteroids first
        asteroids.sort()
        
        for asteroid in asteroids:
            if mass >= asteroid:
                # Destroy the asteroid and absorb its mass
                mass += asteroid
            else:
                # The planet isn't massive enough to destroy this asteroid
                return False
                
        return True
