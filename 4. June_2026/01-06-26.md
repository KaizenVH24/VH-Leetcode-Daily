# Intuition
To minimize the total amount of money we spend, we need to maximize the value of the candies we get for free. 

The rule states that the free candy must cost less than or equal to the minimum of the two candies we just bought. Therefore, to get a highly-priced candy for free, the two candies we buy *must* be even more expensive. 

This leads directly to a **Greedy** strategy:
1. We should buy the two most expensive candies available.
2. We then take the third most expensive candy for free.
3. We repeat this process with the remaining candies until they are all gone.

# Approach
1. **Sort:** Sort the `cost` array in descending order (from most expensive to least expensive).
2. **Group by Three:** Iterate through the sorted array. Conceptually, we are grouping the candies into chunks of three. 
3. **Accumulate Cost:** For each group of three, we pay for the first two (indices `0` and `1` relative to the group) and get the third one (index `2` relative to the group) for free. 
4. **Implementation Detail:** We can keep a running total. We loop through the array with an index `i`. If `(i + 1)` is a multiple of 3 (which corresponds to indices `2, 5, 8...`), it represents a free candy, so we skip adding its cost. Otherwise, we add `cost[i]` to our total.

# Complexity
- **Time complexity:** $\mathcal{O}(N \log N)$
  Where $N$ is the number of candies. Sorting the array is the dominant operation. The subsequent loop takes linear $\mathcal{O}(N)$ time.
  
- **Space complexity:** $\mathcal{O}(1)$ or $\mathcal{O}(N)$
  Depending on the sorting algorithm used under the hood (Python's `sort()` uses Timsort, which takes $\mathcal{O}(N)$ space in the worst case). If we ignore the sorting space, the auxiliary variables take constant $\mathcal{O}(1)$ space.

class Solution:
    def minimumCost(self, cost: list[int]) -> int:
        # Sort candies from most to least expensive
        cost.sort(reverse=True)
        
        total_cost = 0
        
        for i in range(len(cost)):
            # Every 3rd candy (indices 2, 5, 8...) is free
            if i % 3 != 2:
                total_cost += cost[i]
                
        return total_cost
