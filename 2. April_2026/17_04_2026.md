Leetcode 3761. Minimum Absolute Distance Between Mirror Pairs

---

# Intuition
The problem asks us to find the minimum distance between two indices `i` and `j` (where `i < j`) such that `reverse(nums[i]) == nums[j]`. Instead of checking all pairs, which would result in a Time Limit Exceeded (TLE) error, we can iterate through the array once. As we visit each element at index `j`, we want to know if there was a previous element whose reverse equals our current `nums[j]`.

# Approach
1.  **Hash Map for Tracking:** We can use a dictionary (`last_seen_reversed`) to map the reversed value of a number to its index. Specifically, `last_seen_reversed[reverse(nums[i])] = i`.
2.  **Single Pass:** Iterate through the array from left to right. At each index `j`:
    * Check if `nums[j]` exists in our dictionary. If it does, it means we previously saw an element `nums[i]` whose reverse is exactly `nums[j]`.
    * Calculate the distance `j - last_seen_reversed[nums[j]]`. Update the minimum distance found so far.
    * Since we want the *minimum* distance, keeping the most recent index (the largest `i`) for any reversed value is optimal. Therefore, we always update the dictionary with the current index `j` for the key `reverse(nums[j])` before moving to the next element.
3.  **Reversing the Integer:** Convert the integer to a string, reverse the string using Python's slice notation `[::-1]`, and convert it back to an integer. This automatically handles leading zeros (e.g., `120` -> `"021"` -> `21`).

# Complexity
- Time complexity:
$$O(N)$$
We iterate through the array of length $N$ exactly once. Converting to string, reversing, and converting back to an integer takes $O(D)$ time where $D$ is the number of digits. Since the max value is $10^9$, $D \le 10$, making the reversal operation effectively $O(1)$. 

- Space complexity:
$$O(N)$$
In the worst-case scenario (all elements are unique and have unique reversed values), the hash map will store an entry for each of the $N$ elements.

# Code
```python3 []
class Solution:
    def minMirrorPairDistance(self, nums: List[int]) -> int:

        last_seen_reversed = {}
        min_dist = float('inf')
        
        for j, num in enumerate(nums):
            if num in last_seen_reversed:
                min_dist = min(min_dist, j - last_seen_reversed[num])
                
            rev = int(str(num)[::-1])
            last_seen_reversed[rev] = j
            
        if min_dist != float('inf'):
            return min_dist
        else:
            return -1
```
