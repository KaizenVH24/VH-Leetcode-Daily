Leetcode - 1855. Maximum Distance Between a Pair of Values

---

# Intuition
Since both arrays are sorted in non-increasing (descending) order, we can take advantage of their monotonicity to avoid checking every possible pair. If a number `nums1[i]` is smaller than or equal to `nums2[j]`, it will also definitely be smaller than or equal to anything before `j` in `nums2`. To maximize the distance `j - i`, we want to push `j` as far right as possible. When `nums1[i]` finally becomes strictly greater than `nums2[j]`, we must push `i` to the right to find a smaller value in `nums1` that can satisfy the condition. This creates a perfect setup for a Two Pointers approach.

# Approach
1.  Initialize two pointers, `i` for `nums1` and `j` for `nums2`, both starting at `0`.
2.  Maintain a `max_dist` variable to track the highest `j - i` found.
3.  Loop while `i` is within the bounds of `nums1` and `j` is within the bounds of `nums2`:
    * If `nums1[i] <= nums2[j]`: This is a valid pair (the condition `i <= j` is naturally maintained if we handle the pointers correctly). Calculate the distance `j - i`, update `max_dist` if it's larger, and then increment `j` to see if we can stretch the distance even further.
    * If `nums1[i] > nums2[j]`: The pair is invalid. Since moving `j` to the right only makes `nums2[j]` smaller, we have no choice but to increment `i` to find a smaller value in `nums1`. 
    * *Minor optimization/catch:* If `i` ever surpasses `j`, we catch `j` up to `i` because a valid pair strictly requires `i <= j`.
4.  Return `max_dist`.

# Complexity
- Time complexity:
$$O(N + M)$$
Where $N$ is the length of `nums1` and $M$ is the length of `nums2`. Both pointers `i` and `j` only move forward. They traverse their respective arrays at most once, making this a linear time solution.

- Space complexity:
$$O(1)$$
We only use a few integer variables (`i`, `j`, `max_dist`) to keep track of the indices and the answer.

# Code
```python3 []
class Solution:
    def maxDistance(self, nums1: List[int], nums2: List[int]) -> int:

        i, j = 0, 0
        n, m = len(nums1), len(nums2)
        max_dist = 0
        
        while i < n and j < m:
            if nums1[i] <= nums2[j]:
                max_dist = max(max_dist, j - i)
                j += 1
            else:
                i += 1
                if i > j:
                    j = i
                    
        return max_dist
```
