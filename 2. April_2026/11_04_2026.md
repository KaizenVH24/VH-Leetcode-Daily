### Leetcode 3741. Minimum Distance Between Three Equal Elements II ( 11th April, 2026 )

---

# Intuition
The problem is mathematically identical to Part I. For any sorted triplet of indices $i < j < k$ where the values are the same, the distance formula simplifies:
$(j - i) + (k - j) + (k - i) = 2 \times (k - i)$.

To minimize this distance, we need to minimize the gap between the first and third occurrences of a number. This means we only ever need to check triplets of *consecutive* matching numbers. Because the constraints are larger in Part II ($N \le 10^5$), building large lists of indices and looping through them might have slightly higher memory and time overhead. Instead, we can optimize this into a single-pass solution by only remembering the **last two seen indices** for each number.

# Approach
1. **State Tracking:** Since the problem guarantees that $1 \le nums[i] \le n$, we can use two flat arrays of size $n + 1$ instead of a Hash Map. This avoids hashing overhead and makes lookups instantaneously $O(1)$.
   * `first_prev[x]`: Stores the most recently seen index of number `x`.
   * `second_prev[x]`: Stores the second most recently seen index of number `x`.
2. **Single Pass:** Iterate through `nums` with its index `i`.
3. **Calculate on the Fly:** For the current `num`, if `second_prev[num]` is not empty (meaning this is at least the third time we are seeing it), calculate the distance as $2 \times (i - second\_prev[num])$. Update the global minimum if it's smaller.
4. **Shift States:** Update `second_prev[num]` to be `first_prev[num]`, and update `first_prev[num]` to be the current index `i`.
5. Return the minimum distance found, or `-1` if no good tuple was formed.

# Complexity
- Time complexity:
$$O(N)$$
We complete the entire process in a single iteration over the array. State updates and lookups take $O(1)$ time.

- Space complexity:
$$O(N)$$
We allocate two arrays of size $n + 1$ to track the last two positions of each number. This is highly memory-efficient compared to storing variable-length lists for every unique number.

# Code
```python3 []
class Solution:
    def minimumDistance(self, nums: List[int]) -> int:

        n = len(nums)
        first_prev = [-1] * (n + 1)
        second_prev = [-1] * (n + 1)
        min_dist = float('inf')
        
        for i, num in enumerate(nums):
            if second_prev[num] != -1:
                dist = 2 * (i - second_prev[num])
                if dist < min_dist:
                    min_dist = dist
            
            second_prev[num] = first_prev[num]
            first_prev[num] = i
            
        if min_dist != float('inf'):
            return min_dist
        else:
            return -1
```
