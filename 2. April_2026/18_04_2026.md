Leetcode - 3783. Mirror Distance of an Integer

---

# Intuition
The problem simply asks for the absolute difference between a number and its reversed self. In Python, the most efficient and readable way to reverse an integer is to cast it to a string, slice it backwards, and cast it back to an integer.

# Approach
1. Convert the given integer `n` into a string.
2. Use Python's extended slice syntax `[::-1]` to reverse the string. This naturally handles any trailing zeros in the original number (for example, `10` becomes `"01"`).
3. Cast the reversed string back into an integer `new_num`. Python automatically drops the leading zeros during this conversion, so `"01"` safely becomes `1`.
4. Return the absolute difference `abs(n - new_num)`.

# Complexity
- Time complexity:
$$O(D)$$ 
Where $D$ is the number of digits in $n$. Since $n \le 10^9$, it has at most 10 digits. Therefore, the string conversion, reversal, and math operations happen in effectively $O(1)$ constant time.

- Space complexity:
$$O(D)$$
We create a string of length $D$ to hold the reversed number. Again, bounded by 10 characters, this is effectively $O(1)$ constant space.

# Code
```python3 []
class Solution:
    def mirrorDistance(self, n: int) -> int:
        new_num = int(str(n)[::-1])
        return abs(n - new_num)
```
