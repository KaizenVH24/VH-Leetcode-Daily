# Intuition
This is essentially a graph traversal problem mapped onto a grid. We need to navigate from the top-left to the bottom-right, but a move is only valid if two conditions hold: the current street piece has an exit pointing toward the neighbor, and the neighboring street piece has a matching entrance pointing back.

# Approach
1. Map out the valid outgoing directions `(dr, dc)` for all 6 street types.
2. Define the acceptable "receiving" street types for each movement direction. For example, if we move right `(0, 1)`, the piece we land on *must* have an opening on its left side (types 1, 3, or 5).
3. Run a standard Breadth-First Search (BFS) starting from `(0, 0)`.
4. Maintain a `visited` set to avoid getting trapped in infinite loops. If we pull `(m - 1, n - 1)` from the queue, a path exists. If the queue runs dry without hitting the target, no valid path exists.

# Complexity
- Time complexity:
$$O(m \times n)$$
In the worst-case scenario, we visit every cell in the grid exactly once. Dictionary lookups for the valid moves take $O(1)$ time.

- Space complexity:
$$O(m \times n)$$
The BFS queue and the `visited` set scale linearly with the grid size, storing up to $m \times n$ coordinates.

# Code
```python3 []
from collections import deque
from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[int]]) -> bool:
        
        m, n = len(grid), len(grid[0])
        
        directions = {
            1: [(0, -1), (0, 1)],   # Left, Right
            2: [(-1, 0), (1, 0)],   # Up, Down
            3: [(0, -1), (1, 0)],   # Left, Down
            4: [(0, 1), (1, 0)],    # Right, Down
            5: [(0, -1), (-1, 0)],  # Left, Up
            6: [(0, 1), (-1, 0)]    # Right, Up
        }
        
        valid_next = {
            (0, -1): {1, 4, 6}, # Moved Left - Need a street with a Right opening
            (0, 1): {1, 3, 5},  # Moved Right - Need a street with a Left opening
            (-1, 0): {2, 3, 4}, # Moved Up - Need a street with a Down opening
            (1, 0): {2, 5, 6}   # Moved Down - Need a street with an Up opening
        }
        
        queue = deque([(0, 0)])
        visited = {(0, 0)}
        
        while queue:
            r, c = queue.popleft()
            
            if r == m - 1 and c == n - 1:
                return True
            
            for dr, dc in directions[grid[r][c]]:
                nr, nc = r + dr, c + dc
                
                if 0 <= nr < m and 0 <= nc < n and (nr, nc) not in visited:
                    if grid[nr][nc] in valid_next[(dr, dc)]:
                        visited.add((nr, nc))
                        queue.append((nr, nc))
                        
        return False
```
