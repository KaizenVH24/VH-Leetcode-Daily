# Intuition
A brute-force approach to this problem would involve checking every pair of identical elements, resulting in an $O(N^2)$ time complexity. This will cause a Time Limit Exceeded (TLE) error given the constraint $N \le 10^5$. 

Instead, we can group the indices of identical numbers. For any specific number, its list of indices will naturally be sorted. If we know the sum of all indices to the left and all indices to the right of our current position, we can calculate the total distance mathematically in $O(1)$ time per element using prefix and suffix sums.

# Approach
1.  **Group Indices:** Use a Hash Map to store a list of indices for each unique value in `nums`.
2.  **Calculate using Prefix/Suffix Sums:** For each list of grouped indices:
    * First, calculate the total sum of these indices. This will initially act as our `suffix_sum`.
    * Maintain a `prefix_sum` (initially `0`).
    * Iterate through each index in the group. For the current index, subtract it from the `suffix_sum`.
    * The total distance to all identical elements on the **left** is: `(current_index * number_of_left_elements) - prefix_sum`.
    * The total distance to all identical elements on the **right** is: `suffix_sum - (current_index * number_of_right_elements)`.
    * Add these two distances together and store the result in the output array.
    * Add the current index to the `prefix_sum` and move to the next.

# Complexity
- Time complexity:
$$O(N)$$
We iterate through the `nums` array once to group the indices, which takes $O(N)$. Then, we iterate through each index exactly once more across all the groups to calculate the distances, which also takes $O(N)$.

- Space complexity:
$$O(N)$$
We use a Hash Map to store the grouped indices, which will hold exactly $N$ integers in total. We also allocate an output array of size $N$.

# Code
```python3 []
from collections import defaultdict

class Solution:
    def distance(self, nums: List[int]) -> List[int]:

        indices_map = defaultdict(list)
        for i, num in enumerate(nums):
            indices_map[num].append(i)
            
        n = len(nums)
        arr = [0] * n
        
        for indices in indices_map.values():
            k = len(indices)
            if k == 1:
                continue
                
            suffix_sum = sum(indices)
            prefix_sum = 0
            
            for m, idx in enumerate(indices):
                suffix_sum -= idx
                
                left_count = m
                right_count = k - m - 1
                
                left_dist = (left_count * idx) - prefix_sum
                right_dist = suffix_sum - (right_count * idx)
                
                arr[idx] = left_dist + right_dist                
                prefix_sum += idx
                
        return arr
```
