### Leetcode 874. Walking Robot Simulation ( 6th April, 2026 )


# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
The core of this problem is efficiently simulating the robot's movement while checking for obstacles. Since the robot can only move one step at a time up to a maximum of 9 steps per command, we can safely simulate every single step it takes. The critical bottleneck is checking if an obstacle is in the way. If we use a list to search for obstacles, it will cause a Time Limit Exceeded (TLE) error. By converting the obstacles array into a Hash Set of coordinate tuples, we drop the obstacle lookup time from $O(N)$ to $O(1)$.


# Approach
<!-- Describe your approach to solving the problem. -->
1. Direction Array: Represent directions as coordinate changes (dx, dy). If we order them clockwise (North (0, 1), East (1, 0), South (0, -1), West (-1, 0)), turning right is just moving to the next index (curr_dir + 1) % 4, and turning left is moving to the previous index (curr_dir + 3) % 4.

2. Obstacle Set: Convert the obstacles list into a set of tuples (x, y). This makes collision checking instantaneous.

3. Simulate Commands:

- If the command is -1 or -2, update the current direction index.

- If the command is a positive number, move the robot one unit at a time in the current direction.

- Before taking each step, check if the (next_x, next_y) coordinate exists in the obstacle set. If it does, stop processing the current move command immediately (break the inner loop).

- Update the maximum squared Euclidean distance after every successful step.



# Complexity

- Time Complexity: $O(N + K)$, where $N$ is the number of obstacles and $K$ is the total number of steps the robot takes. Constructing the set takes $O(N)$. Moving the robot takes at most $9 \times M$ steps (where $M$ is the number of commands), making the simulation strictly linear relative to the input constraints.

- Space Complexity: $O(N)$ to store the obstacles in a Hash Set.

# Code
```python3 []
class Solution:
    def robotSim(self, commands: List[int], obstacles: List[List[int]]) -> int:

        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        dir_idx = 0  # north
        obs_set = set(map(tuple, obstacles))
        x, y = 0, 0
        max_dist_sq = 0
        
        for cmd in commands:
            if cmd == -1:
                dir_idx = (dir_idx + 1) % 4

            elif cmd == -2:
                dir_idx = (dir_idx + 3) % 4

            else:
                dx, dy = directions[dir_idx]
                for i in range(cmd):
                    if (x + dx, y + dy) in obs_set:
                        break  
                        
                    x += dx
                    y += dy
                    max_dist_sq = max(max_dist_sq, x*x + y*y)
                    
        return max_dist_sq
```
