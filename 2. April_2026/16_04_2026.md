### Leetcode 3488. Closest Equal Element Queries

---


# Intuition
Since we need to process multiple queries on the same array, recalculating the closest element for each query would lead to a Time Limit Exceeded (TLE) error. Instead, we can precalculate the minimum circular distance for *every* index in `nums` in a single pass.

Because the array is circular, the shortest path to an identical element will always be to the immediately adjacent identical elements (either the one right before it or the one right after it). By grouping the indices of identical numbers, we can just check these left and right neighbors.

# Approach
1. **Group Indices by Value:** Create a hash map (or dictionary) where each key is a unique number in `nums`, and the value is a list of indices where that number appears. Since we iterate from left to right, these index lists will naturally be sorted.
2. **Calculate Distances:** Create an `ans_map` array of size $N$ initialized to `-1`. 
3. **Iterate Through Groups:** For each list of indices:
   - If the list has only 1 index, there are no identical elements, so it stays `-1`.
   - If there are multiple indices, iterate through them. For an index at position `i` in the list, its closest neighbors are at `i - 1` and `(i + 1) % k` (to wrap around circularly).
   - The circular distance between two indices `a` and `b` is `min(abs(a - b), n - abs(a - b))`.
   - Take the minimum of the distance to the left neighbor and the right neighbor, and store it in `ans_map`.
4. **Answer Queries:** Loop through the `queries` array and fetch the precalculated results from `ans_map` in $O(1)$ time.

# Complexity
- Time complexity:
$$O(N + Q)$$
Where $N$ is the length of `nums` and $Q$ is the length of `queries`. Grouping the indices takes $O(N)$ time. Calculating the distances takes $O(N)$ because we process each index exactly once across all the groups. Answering the queries takes $O(Q)$.

- Space complexity:
$$O(N)$$
We use extra space for the hash map to store the grouped indices, which holds exactly $N$ elements, and the `ans_map` array of size $N$.

# Code
```python3 []
class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:

        n = len(nums)
        indices_map = defaultdict(list)
        
        for i, num in enumerate(nums):
            indices_map[num].append(i)
            
        ans_map = [-1] * n
        
        def get_dist(i, j):
            d = abs(i - j)
            return min(d, n - d)
            
        for indices in indices_map.values():
            k = len(indices)
            if k > 1:
                for i in range(k):
                    prev_idx = indices[i - 1]
                    next_idx = indices[(i + 1) % k]
                    
                    d1 = get_dist(indices[i], prev_idx)
                    d2 = get_dist(indices[i], next_idx)
                    
                    ans_map[indices[i]] = min(d1, d2)
                    
        return [ans_map[q] for q in queries]
```
