### Leetcode 2463. Minimum Total Distance Traveled ( 14th April, 2026 )

---

# Intuition
The first key insight is that the optimal assignments will never "cross" each other. If we sort both the robots and the factories by their positions from left to right, we can confidently assign robots to factories in sequential order. This structure makes it a perfect candidate for Dynamic Programming. 

# Approach
1. **Sort Everything:** Sort the `robot` array and the `factory` array based on their positions on the X-axis.
2. **Dynamic Programming:** Define a state `dp(i, j)` which represents the minimum distance required to fix the remaining robots starting from index `i`, using the factories starting from index `j`.
3. **Choices at Each Factory:** For the current factory `j`, we have multiple choices:
   - We can assign `0` robots to it and just move on to the next factory `dp(i, j + 1)`.
   - We can assign `1` robot, `2` robots, ..., up to `k` robots (where `k` is bounded by the factory's `limit` and the number of unassigned robots left). 
4. **State Transition:** As we assign `k` robots to factory `j`, we accumulate the distance for each robot. For every valid `k`, the cost is the current accumulated distance plus the recursive result of `dp(i + k, j + 1)`. We take the minimum cost across all these choices.
5. **Memoization:** Store the results of `(i, j)` in a hash map to avoid redundant calculations.

# Complexity
- Time complexity:
$O(N^2 \times M)$
Where $N$ is the number of robots and $M$ is the number of factories. In the worst case, for each state $(i, j)$ of which there are $N \times M$, we iterate up to $N$ times (the maximum limit of a factory). With $N, M \le 100$, this is roughly $10^6$ operations, which easily passes.

- Space complexity:
$O(N \times M)$
For the memoization table (or call stack) which stores a result for every combination of robot index and factory index.

# Code
```python3 []
class Solution:
    def minimumTotalDistance(self, robot: List[int], factory: List[List[int]]) -> int:

        robot.sort()
        factory.sort(key=lambda x: x[0])        
        n = len(robot)
        m = len(factory)
        
        memo = {}
        
        def dp(i, j):
            if i == n:
                return 0

            if j == m:
                return float('inf')
            
            if (i, j) in memo:
                return memo[(i, j)]
            
            res = dp(i, j + 1)
            curr_dist = 0
            pos, limit = factory[j]
            
            for k in range(1, limit + 1):
                if i + k - 1 < n:
                    curr_dist += abs(robot[i + k - 1] - pos)
                    res = min(res, curr_dist + dp(i + k, j + 1))
                else:
                    break
                    
            memo[(i, j)] = res
            return res
            
        return dp(0, 0)
```
