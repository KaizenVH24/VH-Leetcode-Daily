### Leetcode 1848. Minimum Distance to the Target Element ( 13th April, 2026 )

---

# Intuition
Since the array size is extremely small (at most 1000 elements), we don't need to overcomplicate things with outward-expanding pointers or binary search. We can simply scan through the entire array, check every position where the `target` appears, and keep track of the smallest distance to our `start` index. 

# Approach
Set a variable `min_dist` to infinity to track the smallest distance found. Iterate through the array using `enumerate` so we have access to both the index `i` and the value `num`. Whenever `num` matches our `target`, we calculate the absolute difference `abs(i - start)`. We update `min_dist` if this new difference is smaller than what we've seen before. Since the problem guarantees the target exists, we will always find a valid distance.

# Complexity
- Time complexity:
$$O(n)$$
We iterate through the array exactly once. The operations inside the loop (checking equality, calculating absolute difference, and finding the minimum) all take $O(1)$ time. 

- Space complexity:
$$O(1)$$
We only use a single variable to store the minimum distance, which requires constant extra space regardless of the input array's size.

# Code
```python3 []
class Solution:
    def getMinDistance(self, nums: List[int], target: int, start: int) -> int:
        
        min_dist = float('inf')
        
        for i, num in enumerate(nums):
            if num == target:
                min_dist = min(min_dist, abs(i - start))
                
        return min_dist
```
