### Leetcode 2515. Shortest Distance to Target String in a Circular Array

---


# Intuition
In a circular array, there are exactly two ways to get from a starting index to any target index: you can either go directly forward (or backward), or you can wrap around the ends of the array. The distance for the direct route is the absolute difference between the indices. The wrap-around distance is the total length of the array minus that absolute difference. To find the shortest path, we just need to take the minimum of these two options whenever we find the target word.

# Approach
1. Set a variable `min_dist` to infinity to keep track of the shortest path.
2. Iterate through the `words` array using its length `n`.
3. Whenever `words[i]` equals our `target`:
   - Calculate the direct distance: `dist = abs(i - startIndex)`.
   - The wrap-around distance is simply `n - dist`.
   - The shortest distance to this specific target is `min(dist, n - dist)`.
   - Update `min_dist` if this path is shorter than any we've seen so far.
4. If we finish the loop and `min_dist` is still infinity, the target doesn't exist, so return `-1`. Otherwise, return `min_dist`.

# Complexity
- Time complexity:
$$O(N)$$
Where $N$ is the number of elements in the `words` array. We iterate through the array exactly once. The string comparisons take time proportional to the length of the strings, but since string lengths are bounded by 100, we treat the comparison as $O(1)$.

- Space complexity:
$$O(1)$$
We only use a few variables (`n`, `min_dist`, `dist`) which require constant extra space.

# Code
```python3 []
class Solution:
    def closestTarget(self, words: List[str], target: str, startIndex: int) -> int:

        n = len(words)
        min_dist = float('inf')
        
        for i, word in enumerate(words):
            if word == target:
                dist = abs(i - startIndex)
                shortest_to_this_target = min(dist, n - dist)
                
                if shortest_to_this_target < min_dist:
                    min_dist = shortest_to_this_target
                    
        if min_dist != float('inf'):
            return min_dist
        else:
            return -1
```
