### Leetcode 3653. XOR After Range Multiplication Queries I ( 8th April, 2026 )

---

# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
Given the constraints ($N \le 1000$ and $Q \le 1000$), a direct simulation is actually the optimal and intended approach for this version of the problem. The maximum number of operations is $10^6$, which executes in a fraction of a second in Python. We just need to iterate through the queries, update the array elements directly with the modulo arithmetic, and then compute the final XOR sum.


# Approach
<!-- Describe your approach to solving the problem. -->
1. Iterate through Queries: For each query [l, r, k, v], use a standard range(l, r + 1, k) to jump through the targeted indices.
2. Update Elements: Multiply the element at the current index by v and take modulo $10^9 + 7$.
3. Compute XOR: After processing all queries, iterate through the modified nums array and compute the cumulative bitwise XOR.



# Complexity
- Time complexity: $O(n \times q)$ in the worst case (where $k=1$ and the range spans the whole array). Given $n = 1000$ and $q = 1000$, this is roughly $10^6$ operations, comfortably passing within the time limit.

- Space complexity: $O(1)$ beyond the input array, as we modify nums in place.
# Code
```python3 []
class Solution:
    def xorAfterQueries(self, nums: List[int], queries: List[List[int]]) -> int:
        mod = 10**9 + 7

        for l, r, k, v in queries:
            for i in range(l, r+1, k):
                nums[i] = (nums[i]*v) % mod

        ans = 0
        for i in nums:
            ans ^= i
        
        return ans

```
