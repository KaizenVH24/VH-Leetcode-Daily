# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->

Since the robot only moves forward and turns when it hits the grid's boundaries, it will constantly travel along the perimeter of the grid in a counterclockwise direction. It will never move into the interior cells.

Because num can be up to $10^5$, moving step-by-step will result in a Time Limit Exceeded (TLE) error. Instead, we can calculate the total length of the perimeter and use modulo arithmetic to find the robot's exact position instantly. The only edge case is the starting position (0, 0): initially, the robot faces "East", but if it completes a full lap and returns to (0, 0), it arrives by moving down the left edge, meaning it will be facing "South".

# Approach
<!-- Describe your approach to solving the problem. -->

1. Calculate Perimeter: The perimeter length P of a grid is 2 * (width - 1) + 2 * (height - 1).

2. Modulo Arithmetic: Keep a running total of the steps taken, modulo P. We track this in a variable pos.

3. Determine Coordinates and Direction: Based on the value of pos, we can determine which edge of the grid the robot is currently on.

    - Bottom Edge: 0 < pos <= width - 1. The robot is moving right. Facing "East".

    - Right Edge: width - 1 < pos <= width + height - 2. The robot is moving up. Facing "North".

    - Top Edge: width + height - 2 < pos <= 2 * width + height - 3. The robot is moving left. Facing "West".

    - Left Edge: pos > 2 * width + height - 3. The robot is moving down. Facing "South".

4. Handle the Origin: If pos == 0, the robot is at (0, 0). If it has never moved, it faces "East". If it has moved at least once (moved == True), it faces "South".


# Complexity
- Time complexity: $O(1)$ for all operations (__init__, step, getPos, getDir). Modulo arithmetic allows us to skip the simulation entirely.

- Space complexity: $O(1)$ since we are only storing a few integer variables representing the grid dimensions and the current state.

# Code
```python3 []
class Robot:

    def __init__(self, width: int, height: int):
        
        self.w = width
        self.h = height
        self.p = 2 * (width - 1) + 2 * (height - 1)
        self.pos = 0
        self.moved = False

    def step(self, num: int) -> None:
        
        self.moved = True
        self.pos = (self.pos + num) % self.p

    def getPos(self) -> List[int]:
        
        if self.pos == 0:
            return [0, 0]
        
        p1 = self.w - 1
        p2 = self.w + self.h - 2
        p3 = 2 * self.w + self.h - 3
        
        if self.pos <= p1:
            return [self.pos, 0]

        elif self.pos <= p2:
            return [self.w - 1, self.pos - p1]

        elif self.pos <= p3:
            return [self.w - 1 - (self.pos - p2), self.h - 1]

        else:
            return [0, self.h - 1 - (self.pos - p3)]

    def getDir(self) -> str:
        
        if self.pos == 0:
            return "South" if self.moved else "East"
        
        p1 = self.w - 1
        p2 = self.w + self.h - 2
        p3 = 2 * self.w + self.h - 3
        
        if self.pos <= p1:
            return "East"

        elif self.pos <= p2:
            return "North"

        elif self.pos <= p3:
            return "West"
            
        else:
            return "South"
```
