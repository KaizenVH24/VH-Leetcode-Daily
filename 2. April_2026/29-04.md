# Intuition
The problem asks us to find the optimal heights of black cells in each column to maximize the score. A white cell at `(r, c)` contributes its value if it has a horizontally adjacent black cell. This means it is activated if the number of black cells in the left column ($c_{c-1}$) is greater than $r$, or if the right column ($c_{c+1}$) is greater than $r$. 

Because a cell's activation strictly depends on its own column's state and its immediate left and right neighbors, we can assign the scoring to the columns themselves. For any column `c`, the white cells in this column (which start from row $c_c$) are activated up to the maximum height of its neighbors $\max(c_{c-1}, c_{c+1})$.
This localized property allows us to formulate a Dynamic Programming solution where we only need to track the heights of the previous column and the current column to calculate the score of the *previous* column.

# Approach
Let $N$ be the size of the grid. 
Let $c_i$ represent the number of black cells chosen for column $i$.
We evaluate the score column by column. The score contributed by the white cells specifically in column $i$ is exactly the sum of cells in rows $r$ where $c_i \le r < \max(c_{i-1}, c_{i+1})$. 

We can define our DP state: `dp[x][y]` is the maximum score for all evaluated columns given that the previous column height was $x$ and the current column height is $y$.

1.  **Prefix Sums:** We precompute column-wise prefix sums of the grid to quickly query the sum of `grid[r][c]` for $r$ in any range.
2.  **Initialization:** For column 0, we assume a dummy left neighbor $c_{-1} = 0$. For all combinations of $x = c_0$ and $y = c_1$, the score in column 0 is the sum of rows from $x$ to $y-1$ (if $y > x$).
3.  **State Transition:** For each subsequent column `col` from 1 to $N-2$, we transition from `dp` to `new_dp`. 
    For a fixed $x = c_{col}$ and $y = c_{col+1}$, we iterate over all possible heights $z = c_{col-1}$:
    $$new\_dp[x][y] = \max_z \Big( dp[z][x] + \text{score in column } col \Big)$$
    The score in column `col` is the sum of rows from $x$ up to $\max(z, y) - 1$.
4.  **Optimization to $O(N^3)$:** A naive transition checks all $z$ for every $x$ and $y$, taking $O(N^4)$. We can optimize this! The evaluation $\max(z, y)$ splits naturally into two cases:
    * $z \le y$: The max is $y$. The score added is constant with respect to $z$. We can precompute the maximum of `dp[z][x]` for $z \le y$.
    * $z > y$: The max is $z$. The score added depends on $z$ but *not* on $y$. We can precompute the suffix maximums of `dp[z][x] + score(z)`.
    By precomputing these prefix and suffix maximums for each $x$, we compute `new_dp[x][y]` in $O(1)$, reducing the overall time complexity to $O(N^3)$.
5.  **Final Evaluation:** For the final column $N-1$, we assume a dummy right neighbor $c_N = 0$ and add its contribution to get the absolute maximum score.

# Complexity
- **Time complexity:** $O(N^3)$. There are $N$ columns to process. For each column, calculating the prefix/suffix maximums takes $O(N^2)$, and populating the DP table takes $O(N^2)$. Thus, the time is strictly bounded by $O(N^3)$, which easily passes within limits for $N \le 100$.
- **Space complexity:** $O(N^2)$ to store the 2D `dp` tables of size $(N+1) \times (N+1)$ and the `pref` prefix sum array.

# Code
```python3 []
class Solution:
    def maximumScore(self, grid: List[List[int]]) -> int:

        n = len(grid)
        if n == 1:
            return 0

        pref = [[0] * (n + 1) for _ in range(n)]
        for c in range(n):
            for r in range(n):
                pref[c][r + 1] = pref[c][r] + grid[r][c]

        # Initialize DP for column 0
        dp = [[0] * (n + 1) for _ in range(n + 1)]
        for x in range(n + 1):
            for y in range(n + 1):
                dp[x][y] = max(0, pref[0][y] - pref[0][x])

        # Evaluate columns from 1 to n - 2
        for col in range(1, n - 1):
            new_dp = [[0] * (n + 1) for _ in range(n + 1)]
            P = pref[col]
            
            for x in range(n + 1):
                # 1. Precompute prefix maximums for z <= y
                pref_max = [-float('inf')] * (n + 1)
                curr_max = -float('inf')
                for z in range(n + 1):
                    if dp[z][x] > curr_max:
                        curr_max = dp[z][x]
                    pref_max[z] = curr_max

                # 2. Precompute suffix maximums for z > y
                suff_max = [-float('inf')] * (n + 2)
                curr_max = -float('inf')
                for z in range(n, -1, -1):
                    val = dp[z][x] + max(0, P[z] - P[x])
                    if val > curr_max:
                        curr_max = val
                    suff_max[z] = curr_max


                for y in range(n + 1):
                    # Case A: Left neighbor z <= Right neighbor y
                    ans1 = pref_max[y] + max(0, P[y] - P[x])
                    # Case B: Left neighbor z > Right neighbor y
                    ans2 = suff_max[y + 1]
                    
                    new_dp[x][y] = max(ans1, ans2)

            dp = new_dp

        # Evaluate the final column (n - 1)
        ans = 0
        for x in range(n + 1):
            for y in range(n + 1):
                score = dp[x][y] + max(0, pref[n - 1][x] - pref[n - 1][y])
                if score > ans:
                    ans = score

        return ans
```
