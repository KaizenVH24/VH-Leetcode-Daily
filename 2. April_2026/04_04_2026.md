
### Leetcode 2075. Decode the Slanted Ciphertext ( 4th April, 2026 )

---

# Intuition

The encoded text is essentially a 1D representation of a 2D matrix read row by row. Since we know the number of rows and the total length of the string, we can easily figure out the number of columns. The original text was written diagonally, so to decode it, we just need to read the characters by jumping through the 1D string at the correct diagonal intervals.

# Approach

1. **Find Grid Dimensions:** Calculate the number of columns by dividing the length of `encodedText` by `rows`. 
2. **Iterate Diagonally:** The first diagonal starts at column 0, row 0. The next starts at column 1, row 0, and so on. 
3. **Map 2D to 1D:** For any cell at `(row, col)`, its 1D index in the `encodedText` string is `row * cols + col`. We can collect these characters by iterating down each diagonal until we hit the bottom or right edge of the matrix.
4. **Clean up:** The problem states the original text has no trailing spaces, but empty matrix cells are padded with spaces. We use `.rstrip()` to remove the trailing padding at the end.

# Complexity

- Time complexity:
$$O(L)$$
Where $L$ is the length of `encodedText`. We iterate through the string and append characters to an array exactly $L$ times. String joining and stripping also take $O(L)$ time.

- Space complexity:
$$O(L)$$
We use an array of characters (`res`) to build the decoded string before joining it, which requires $O(L)$ space.

# Code
```python3 []
class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:

        length = len(encodedText)
        cols = length // rows
        
        res = []
        
        for start_col in range(cols):
            for row in range(rows):
                col = start_col + row
                if col >= cols:
                    break
                
                idx = row * cols + col
                res.append(encodedText[idx])
                
        return "".join(res).rstrip()
```
