# Intuition
To solve this problem, we need to answer two critical questions:
1.  **Is it even possible?** You can only make two numbers equal by adding or subtracting `x` if the difference between them is a multiple of `x`. This means every single number in the grid must leave the exact same remainder when divided by `x` (i.e., `num % x` must be identical for all elements). If we find even one number with a different remainder, we can immediately return `-1`.
2.  **What number should we target?** If it is possible, we need to pick a target value to make all numbers equal. In mathematics, to minimize the sum of absolute differences (which directly corresponds to our number of operations), the optimal target is always the **median** of the dataset. (Note: the *mean/average* minimizes *squared* differences, but the *median* minimizes *absolute* differences).

# Approach
1.  **Flatten and Sort:** Extract all the numbers from the 2D `grid` into a 1D array. Sorting this array will allow us to easily find the median.
2.  **Feasibility Check:** Take the remainder of the first element (`arr[0] % x`). Loop through the rest of the array. If any element has a different remainder modulo `x`, return `-1`.
3.  **Find the Median:** Since the array is sorted, the median is simply the element at the middle index: `arr[len(arr) // 2]`. (If the array has an even length, picking either of the two middle elements yields the same minimum operations, so integer division works perfectly).
4.  **Count Operations:** Iterate through the array one last time. For each number, calculate the absolute difference between it and the median, divide by `x`, and add this to a total operations counter.

# Complexity
- Time complexity:
$$O(N \log N)$$
Where $N = m \times n$, the total number of elements in the grid. Flattening the grid takes $O(N)$. Sorting the 1D array is the bottleneck and takes $O(N \log N)$. The subsequent passes to check remainders and count operations take $O(N)$ time.

- Space complexity:
$$O(N)$$
We create a 1D array to store all $N$ elements from the grid so that we can sort them and find the median. 

# Code
```python3 []
class Solution:
    def minOperations(self, grid: list[list[int]], x: int) -> int:
        # Flatten the 2D grid into a 1D list
        arr = []
        for row in grid:
            arr.extend(row)
            
        # Sort to easily find the median later
        arr.sort()
        
        # Check if it's possible to make all elements equal
        remainder = arr[0] % x
        for num in arr:
            if num % x != remainder:
                return -1
                
        # The optimal target is the median
        median = arr[len(arr) // 2]
        
        # Calculate the total number of operations
        ops = 0
        for num in arr:
            ops += abs(num - median) // x
            
        return ops
