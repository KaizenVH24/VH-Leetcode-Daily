Leetcode 3740. Minimum Distance Between Three Equal Elements I ( 10th April, 2026 )

---

# Intuition
The distance formula for a good tuple $(i, j, k)$ is $abs(i - j) + abs(j - k) + abs(k - i)$. 
If we assume the indices are sorted such that $i < j < k$, this formula simplifies neatly:
$(j - i) + (k - j) + (k - i) = 2 \times (k - i)$.

This means the distance is entirely determined by the gap between the smallest and largest indices in the triplet. To minimize this gap, we should only consider triplets of identical numbers that are *consecutive* in their occurrences. There is no benefit to skipping over a matching number, as it would only widen the gap $k - i$.

# Approach
1. **Group Indices:** Iterate through the array and store the indices of each number in a hash map (`indices_map`).
2. **Scan Windows of 3:** For every number that appears at least 3 times, look at every consecutive window of 3 indices (e.g., the 1st, 2nd, and 3rd occurrences; then the 2nd, 3rd, and 4th).
3. **Calculate and Track Minimum:** Compute the distance as $2 \times (idx[m+2] - idx[m])$ and keep track of the minimum value found.
4. If no number appears at least 3 times, return `-1`.

# Complexity
- Time complexity:
$O(N)$
We iterate through the array once to build the map, and then iterate through the lists of indices once. Since the sum of the lengths of all lists is exactly $N$, the overall time is linear.

- Space complexity:
$O(N)$
The hash map stores exactly $N$ indices across all its lists.

# Code
```python3 []
class Solution:
    def minimumDistance(self, nums: List[int]) -> int:

        indices_map = defaultdict(list)
        
        for i, num in enumerate(nums):
            indices_map[num].append(i)
            
        min_dist = float('inf')
        
        for indices in indices_map.values():
            if len(indices) >= 3:
                for j in range(len(indices) - 2):
                    dist = 2 * (indices[j + 2] - indices[j])
                    if dist < min_dist:
                        min_dist = dist
                        
        if min_dist != float('inf'):
            return min_dist
        else:
            return -1
```
